<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web runtime → worker runtime | web 只能 enqueue，不能隐式启动 consumer 或与 worker 生命周期耦合 |
| platform seam → BullMQ clients | feature code 只能通过 infra seam 创建 queue/worker/events，不能直接接触 raw client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-01 | T | `src/features/async-tasks/infra/connection.ts` | mitigate | 独立 BullMQ env capability 与 role-specific connections，避免错误复用 realtime Redis 单例 |
| T-40-02 | D | `src/server/workers/async-task-worker.ts` | mitigate | 独立 entrypoint 和 package scripts，禁止 web/HMR 自动启动 worker |
| T-40-03 | E | `src/features/async-tasks/infra/bullmq.ts` | mitigate | 通过 centralized factory 限制 raw BullMQ client 的扩散边界 |
</threat_model>
