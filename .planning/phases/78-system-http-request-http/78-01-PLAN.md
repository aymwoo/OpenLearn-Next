  <action>
    Create `src/features/system-commands/ssrf-guard.ts` with `import "server-only";` at top (per established project pattern).

    Implement five exported functions:

    1. **validateUrl(rawUrl: string): URL** — HTTPS-only enforcement per D-12.
       - Parse with `new URL(rawUrl)`.
       - If `url.protocol !== "https:"`, throw `new Error("SSRF_HTTPS_REQUIRED")`.
       - If `url.hostname` is empty, throw `new Error("SSRF_NO_HOSTNAME")`.
       - Return the parsed URL object.

    2. **isHostnameRawIP(hostname: string): boolean** — pre-flight IP detection per RESEARCH.md Pitfall 1.
       - Strip brackets if hostname starts with `[` and ends with `]`.
       - Return `net.isIP(stripped) !== 0`.

    3. **isPrivateIP(hostnameOrIP: string): boolean** — comprehensive private/loopback/reserved IP check.
       - First, strip brackets (IPv6 literal format).
       - Use `net.isIP()` to determine the IP family:
         - If `net.isIP(stripped) === 4`: use integer-range check against PRIVATE_IPV4_RANGES (see RESEARCH.md §Pattern 2 for exact hex ranges: 0x00000000-0x00FFFFFF, 0x0A000000-0x0AFFFFFF, 0x7F000000-0x7FFFFFFF, 0xA9FE0000-0xA9FEFFFF, 0xAC100000-0xAC1FFFFF, 0xC0A80000-0xC0A8FFFF, 0x64400000-0x647FFFFF). Convert dotted quad to integer with `ip4ToInt(ip)` shifting each octet.
         - If `net.isIP(stripped) === 6`: check for `::1` (loopback), `fe80::` prefix (link-local), `fc00::` prefix (ULA), `::ffff:` prefix (IPv4-mapped — extract the trailing dotted quad after `::ffff:` and delegate to isPrivateIPv4).
         - If neither family (isIP returns 0), return false (not a raw IP; will be DNS-resolved later).
       - Helper: `ip4ToInt(ip: string): number` — split by `.`, reduce with `(acc << 8) + parseInt(octet, 10), 0) >>> 0`.

    4. **createPinnedAgent(hostname: string, timeout: number): Agent** — DNS-pinned undici Agent per D-09 and D-11.
       - If `isHostnameRawIP(hostname)`: validate with `isPrivateIP`. If private, throw. If safe, create agent that pins to the raw IP address directly via `connect.lookup` callback returning `(null, hostname, family)`.
       - Otherwise: create `new Agent({ connect: { lookup(hostname, options, callback) { ... } }, bodyTimeout: timeout, headersTimeout: 10000 })`.
       - Inside `connect.lookup`:
         - Resolve via `dns.promises.resolve4(hostname)`.
         - If addresses array is empty, callback with `Error("SSRF_DNS_NO_ADDRESS")`.
         - For each address, run `isPrivateIP(address)`. If any is private, callback with `Error("SSRF_PRIVATE_IP_BLOCKED")`.
         - If all addresses are safe, callback with `(null, addresses[0], 4)` to pin.
         - Catch errors and callback with the error.
       - `bodyTimeout` from the timeout parameter (30s default from handler), `headersTimeout` fixed at 10s.

    5. **MAX_REDIRECTS** constant: export `const MAX_REDIRECTS = 5` per D-10.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Plugin payload → authorize() | Untrusted payload.url and payload.method cross the plugin boundary into system handler |
| authorize() → pluginRegistrations DB | manifestJson stored in DB is trusted (written by install flow with schema validation) |
| execute() → network (undici fetch) | Untrusted external server response crosses network boundary |
| execute() → governanceAudits DB | Audit trail must be written before exception throw (audit-then-throw ordering) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-78-01 | Spoofing | execute() → fetch | mitigate | DNS pinning in createPinnedAgent prevents DNS spoofing redirecting to attacker IPs |
| T-78-02 | Tampering | execute() → response body | mitigate | Response body accumulated via authenticated TLS connection; undici handles TLS verification |
| T-78-03 | Repudiation | audit.ts writeSystemCommandAudit | mitigate | Audit record written BEFORE any throw — every denial has a traceable audit row |
| T-78-04 | Information Disclosure | SSRF via private IP | mitigate | Full private IP coverage: 7 IPv4 ranges + IPv6 loopback/ULA/link-local/IPv4-mapped; bracket strip + WHATWG normalization prevent bypass |
| T-78-05 | Denial of Service | execute() → response body | mitigate | 5MB hard truncation via stream accumulation with byte counter; 30s timeout via bodyTimeout |
| T-78-06 | Elevation of Privilege | Redirect chain | mitigate | Manual redirect loop (maxRedirections=0, manual 3xx handling, max 5 hops) with per-hop SSRF+HTTPS+manifest re-validation |
| T-78-07 | Tampering | DNS resolution | mitigate | DNS resolved and pinned in single connect.lookup callback — no TOCTOU window for DNS rebinding (CVE-2026-41272) |
| T-78-08 | Information Disclosure | HTTPS downgrade | mitigate | validateUrl rejects non-https:// protocol before any network I/O (D-12) |
| T-78-09 | Information Disclosure | IPv6 bracket bypass | mitigate | isHostnameRawIP strips brackets before net.isIP(); [::1] correctly detected as IP (Pitfall 1) |
| T-78-10 | Information Disclosure | Decimal IP encoding bypass | mitigate | IP detection on WHATWG-normalized URL.hostname not raw input; http://2130706433/ normalizes to 127.0.0.1 (Pitfall 2) |
| T-78-11 | Information Disclosure | IPv4-mapped IPv6 bypass | mitigate | ::ffff: prefix detected, embedded IPv4 extracted and validated against private ranges (Pitfall 3) |
| T-78-SC | Tampering | npm install undici | mitigate | Package Legitimacy Audit in RESEARCH.md confirms undici is approved (npm registry verified, 500M+ weekly downloads, github.com/nodejs/undici); [SLOP] none found |
