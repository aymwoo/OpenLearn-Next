## New UI Surface Inventory (bounded)

The entire deliverable is three tightly-scoped pieces inside the existing edit-mode workspace:

| # | Element | Placement | Reuse |
|---|---------|-----------|-------|
| 1 | **「AI 起草」trigger button** | Flow-main header action row, alongside the existing 「保存」button (workspace lines ~295–303, the `flex flex-wrap items-center justify-end gap-2` cluster) | `Button` `variant="primary"` (gradient), `Sparkles` lucide icon |
| 2 | **Intent input panel** — `stepType` segmented control (内容/任务/测验) + `intent` text field + 「生成草稿」submit | Lightweight inline panel/popover that opens below the trigger inside the Flow-main `Card` (`bg-surface-container-lowest`); must NOT introduce a new full-screen route | Input styling per DESIGN.md §5.3; segmented control mirrors existing `libraryFilters` pill pattern (workspace lines 214–225) |
| 3 | **Result handoff** — loading/disabled states + success toast that lights up the existing Phase 64 draft-discovery hint / `?mode=review` badge | In place; success path defers entirely to the existing review surface | Phase 64 draft-discovery prompt (do NOT rebuild) |

**Flag-disabled contract (D-03 / D-03a):** When `lesson_agent_enabled` is OFF, the frontend **HIDES** the 「AI 起草」trigger entirely (no disabled-with-tooltip ghost). Rationale: D-03a treats the backend `AGENT_DISABLED` `ActionResult` as the source of truth, and DESIGN.md §11 forbids interface clutter — a permanently-dead control is noise. The backend `AGENT_DISABLED` return is the **fallback safety net** surfaced as an error toast if the action is reached anyway (race / stale client). The trigger's visibility is driven by the agent-enabled flag passed from the server component into the workspace; never trust a client-only flag for enforcement.

## Interaction States

| State | Visual contract |
|-------|-----------------|
| Trigger hidden | `lesson_agent_enabled` OFF → control not rendered (flag from server component) |
| Trigger idle | Primary gradient button, `Sparkles` icon + `AI 起草`, `min-h-12`, hover `-translate-y-0.5` |
| Panel open | Inline panel/popover on `surface-container-lowest`, tonal-separated (no border), `shadow-ambient` |
| Submitting | Submit button disabled + label `正在生成草稿…`; trigger and form inputs disabled; no spinner-only dead UI — keep label text |
| Success | Toast `AI 草稿已生成，去审校 →`; panel closes; existing draft-discovery hint / `?mode=review` badge lights up (Phase 64, reused) |
| Error (generation) | Toast `草稿生成失败，请稍后重试。`; panel stays open with entered values preserved |
| Error (AGENT_DISABLED fallback) | Toast `AI 起草功能未启用。`; panel closes |

Disabled styling inherits `Button` defaults (`disabled:opacity-55 disabled:pointer-events-none`). Focus-visible outline `2px primary` per `globals.css`.
