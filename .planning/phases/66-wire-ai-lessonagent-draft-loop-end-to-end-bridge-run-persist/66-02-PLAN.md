<objective>
Bridge the LessonAgent orchestration entry so a successful `lesson.draft.run` is followed by a
`lesson.draft.persist` dispatch — closing the gap where the agent produces a step but never writes
a draft version. Per locked decision D-01: sequential dispatch at the orchestration entry (NOT nested
dispatch inside the run handler), sharing one correlationId. The run resultSummary returns a single
`step`; the persist payload schema requires `steps: []` (min 1), so wrap as `[step]`.

Purpose: DRAFT-01 (agent draft persists to a draft lesson version via Command Bus) and DRAFT-02
(idempotent / replay-safe persist) require the run output to actually reach the persist command path.
Output: draftLessonStep dispatches run then persist, returns the persisted draft identity.
</objective>
