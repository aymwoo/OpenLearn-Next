# Phase 08 Plan 03: Fix Teacher Dashboard Layout

## Goal
Fix the layout confusion in the Teacher Dashboard where the title "今天把'编程基础：让角色动起来'编排成可运行课堂" has insufficient width and wraps poorly.

## Context
During UAT, the user reported that the title section width was too narrow. This is likely caused by the grid layout `xl:grid-cols-[1.15fr_0.85fr]` or a max-width class constraint that is too aggressive.

## Steps

1. **Update `TeacherDashboardSurface` layout**:
   - In `src/components/surfaces/teacher-dashboard-surface.tsx`.
   - Update the top section grid from `xl:grid-cols-[1.15fr_0.85fr]` to a better ratio like `xl:grid-cols-[1.5fr_1fr]` or `xl:grid-cols-2`.
   - Remove or increase the `max-w-3xl` constraint on the `<h1>` tag to allow it to expand.
   - Also check the paragraph text `max-w-2xl` constraint.
   - Adjust `text-[2rem]` responsive sizing if it's contributing to awkward wrapping on medium screens.

2. **Verify changes**:
   - Ensure the layout is clean without legacy border styles.
   - Ensure the text has sufficient space to display correctly.

## Hand-off
The developer will modify the Tailwind classes in the component to expand the width of the title block.
