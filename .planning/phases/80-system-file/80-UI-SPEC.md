## Copywriting Contract

> Phase 80 为纯后端阶段，无终端用户交互文案。以下为 API 错误响应体中的结构化错误信息文案约定。

| Element | Copy / Convention |
|---------|-------------------|
| API Error: 单文件超限 | HTTP 413 — `{ "error": "file_too_large", "maxBytes": 52428800, "actualBytes": {N}, "exceededBy": {N} }` |
| API Error: 总容量超限 | HTTP 507 — `{ "error": "quota_exceeded", "currentBytes": {N}, "quotaBytes": {N}, "exceededBy": {N} }` |
| API Error: 路径未授权 | HTTP 403 — `{ "error": "path_not_allowed", "requestedPath": "{path}", "allowedPaths": ["{prefix}"] }` |
| API Error: 操作未授权 | HTTP 403 — `{ "error": "operation_not_allowed", "requestedOperation": "{op}", "allowedOperations": ["upload","download","delete","list","metadata"] }` |
| API Error: 文件不存在 | HTTP 404 — `{ "error": "file_not_found", "fileId": "{id}" }` |
| API Error: 跨插件/跨校 | HTTP 403 — `{ "error": "access_denied", "reason": "school_mismatch \| plugin_isolation" }` |
| GC 脚本输出 | stdout — `GC complete: {N} files deleted, {bytes} freed, {time}s elapsed` |

**Source:** CONTEXT.md D-12 超限结构化错误
