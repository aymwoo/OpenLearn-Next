<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RSC page -> PluginRenderer | Page-provided school/context data selects enabled plugins and safe context payload. |
| Plugin hook result -> React widget | Stored/action-generated proposal payload becomes visible UI. |
| Settings forms -> Server Actions | Theme/plugin control forms mutate cookie or plugin state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | XSS/T | `PluginWidget` | mitigate | Render only typed React fields from local components; no `dangerouslySetInnerHTML`, no plugin-supplied component names, no script tags. |
| T-11-03-02 | E | Dashboard/editor plugin anchors | mitigate | Pass school context into `PluginRenderer`; Plan 11-01 DAL enforces school scope again before dispatch. |
| T-11-03-03 | E | Settings plugin manager | mitigate | Use Server Actions from Plan 11-01; no direct DB import in UI; action/DAL checks remain authoritative. |
| T-11-03-04 | T | Theme selector | mitigate | Only list `getValidThemesForSchool(schoolId)` options; active cookie IDs are revalidated by `ThemeInjector`. |
| T-11-03-05 | I | Plugin/private manifest data | mitigate | Display only plugin name/status/kill-switch/enabled state; do not render raw manifest JSON or provider keys. |
</threat_model>
