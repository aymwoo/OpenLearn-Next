<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student browser -> presence action/route | Runtime connection state and current step are reported from client to server. |
| Snapshot/SSE route -> DAL | Route handlers request authoritative classroom state. |
| Student URL query -> player DTO | User-selected `stepId` attempts to influence current step. |
| Teacher control panel -> classroom actions | Expected version controls state mutation concurrency. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05-01 | E | `getStudentPlayerPersonalDTO` | mitigate | Server-side locked mode forces `classroomSessions.activeStepId` over `selectedStepId`; test direct URL bypass. |
| T-11-05-02 | E/I | `getClassroomSnapshotDTO` late join | mitigate | Ensure participant only for authorized class members; unaffiliated users still receive `CLASSROOM_PARTICIPANT_REQUIRED`/403. |
| T-11-05-03 | T | Presence update path | mitigate | Zod-validate `sessionId`, `connectionState`, `currentStepId`; DAL verifies current user/student membership before update. |
| T-11-05-04 | T/R | Classroom control writes | mitigate | Preserve optimistic `expectedVersion` checks and return latest snapshot on conflicts. |
| T-11-05-05 | D | SSE polling route | mitigate | Keep `no-store`, abort handling, and graceful close on 401/403/404; no DB writes in Edge/SSE route except through chosen Node-safe action/route path. |
</threat_model>
