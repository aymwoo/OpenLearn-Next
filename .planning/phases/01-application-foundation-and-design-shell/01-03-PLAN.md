| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-01-10 | Information Disclosure | editor shell | mitigate | Use only `src/lib/demo-data.ts` constants; no DB/DAL imports, no Server Actions, no cookies/headers/auth calls. |
| T-01-11 | Tampering | visual shell | mitigate | Use shared Button/Card/RouteShell primitives; no imported UI registry blocks, 1px section divider utilities, or pure black text. |
