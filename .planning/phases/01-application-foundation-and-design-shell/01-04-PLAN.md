<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public browser→Student/classroom/admin shells | Public routes preview protected-looking surfaces without access control. |
| Static classroom state→User perception | Classroom lock and participant UI is illustrative, not live state. |
| Library/admin shells→Future data paths | Static resource/course/admin UI must not leak into real data implementation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-13 | Spoofing | `/student`, `/classroom`, `/admin` | mitigate | Keep role navigation public per D-05 and avoid signed-in/session claims; admin remains low-emphasis per D-08. |
| T-01-14 | Information Disclosure | `ClassroomConsoleSurface` | mitigate | Render only deterministic participants from `demo-data.ts`; no SSE, cookies, headers, auth, DB, or live classroom APIs. |
| T-01-15 | Tampering | `LibrarySurface` | mitigate | Use local static course/resource cards only; no upload handler, external file source, remote asset, or third-party registry UI. |
| T-01-16 | Elevation of Privilege | `AdminSurface` | mitigate | Do not expose school/user management forms or access-control controls in Phase 1 admin shell. |
</threat_model>
