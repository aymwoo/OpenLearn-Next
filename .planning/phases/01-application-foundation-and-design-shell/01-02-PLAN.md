| Boundary | Description |
|----------|-------------|
| Static constants→UI | Demo content enters UI without persistence or user identity. |
| Role preview→User perception | Local UI state may be mistaken for authentication. |
| Component library→Rendered shell | Shared primitives influence every route shell. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-06 | Information Disclosure | `src/lib/demo-data.ts` | mitigate | Keep deterministic educational sample content only; no personal identifiers beyond fictional Chinese names and no real school data. |
| T-01-07 | Elevation of Privilege | `src/lib/navigation.ts` | accept | Phase 1 routes are intentionally public per D-05; real access control belongs to later auth work and must not be simulated here. |
| T-01-08 | Tampering | `src/components/ui/*` | mitigate | Hand-author components; block shadcn init, third-party registry UI, arbitrary CSS/script, and border-heavy imported skins. |
</threat_model>
