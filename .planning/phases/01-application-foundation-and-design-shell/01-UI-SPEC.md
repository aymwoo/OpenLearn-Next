# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — use Tailwind CSS v4 theme variables and hand-authored components bound to `DESIGN.md` + Stitch project `5322129002350954765`; shadcn is intentionally not initialized in Phase 1 because default border-heavy presets conflict with the no-line tonal system. |
| Preset | not applicable |
| Component library | Radix UI primitives only where accessibility behavior is needed; visual styling must be custom tonal layering, not imported UI-kit skins. |
| Icon library | lucide-react; sparse semantic icons only, 20px default and 24px for primary navigation/hero actions. |
| Font | Lexend exclusively via `next/font/google`; no fallback display font in authored CSS beyond system fallback generated by Next. |

**Binding source:** Stitch project `5322129002350954765` (“晨曦在线课堂”) plus local `DESIGN.md`. Implemented route shells must map: homepage, teacher dashboard, student dashboard, editor, player, immersive player, classroom console, resource center, and course center.

**Required visual language:** The Luminous Academy / Sunlit Studio + The Tactile Horizon: Simplified Chinese UI, premium K-12 atmosphere, intentional asymmetry, tonal islands, no sectioning borders, glass floating surfaces, blue gradient CTAs, Growth Green only for success/achievement.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, compact badge internals |
| sm | 8px | Compact element spacing, chip gaps, control clusters |
| md | 16px | Default element spacing, form row gaps, card internal rhythm |
| lg | 24px | Section padding, dashboard card groups, mobile shell padding |
| xl | 32px | Layout gaps, desktop card grids, route shell content gutters |
| 2xl | 48px | Major section breaks, hero/card separation, editor pane spacing |
| 3xl | 64px | Page-level spacing, public landing hero whitespace, desktop top/bottom breathing room |

Exceptions: icon-only interactive targets must be at least 44px × 44px; primary rounded-full CTAs must be at least 48px tall; large tonal containers may use 40px internal padding when matching Stitch hero/action-card proportions; floating glass nav may use 12px blur padding while preserving 8px grid alignment.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading | 24px | 600 | 1.2 |
| Display | 56px | 600 | 1.05 |

Typography constraints:
- Use exactly these four authored sizes for Phase 1 shells unless a Stitch-mapped hero requires responsive scaling down on mobile.
- Use only two weights: regular `400` and semibold `600`.
- Display text uses `letter-spacing: -0.02em`; labels may use `letter-spacing: 0.05em` only for utility/status text such as “课堂同步” or “今日任务”.
- Body instructional copy must remain 16px minimum; do not use 12px for core learning or navigation text.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `surface` #f5f6f7 | App background, public/teacher/student/classroom/admin route floors, large calm canvas areas |
| Secondary (30%) | `surface-container-low` #eff1f2 | Sidebars, route shell navigation zones, wide content bands, nested panels; primary action cards use `surface-container-lowest` #ffffff on top of this layer |
| Accent (10%) | `primary` #005da7 → `primary_container` #68abff gradient at 135° | Primary CTA, active navigation pill, current lesson/step indicator, progress emphasis, selected route state, hero glow only |
| Destructive | `error` #b31b25 | Destructive actions only: remove draft, archive lesson, leave classroom, delete resource placeholder |

Accent reserved for: primary CTA buttons (`开始备课`, `进入课堂`, `继续学习`), active route/nav pill, focused input ghost-border, current step/progress highlight, selected dashboard card emphasis, and hero/landing gradient glow. Never use accent for every clickable element.

Additional semantic rules:
- Success/achievement uses `tertiary` #386700 or `tertiary_container` #a4fd4c only after positive completion/progress events.
- Text uses `on_surface` #2c2f30; never pure black.
- Secondary text uses `on_surface_variant` #595c5d.
- Ghost border fallback uses `outline_variant` #abadae at 15% opacity, or primary at 20% opacity for focused fields.
- Shadows are ambient only: tinted `rgba(44, 47, 48, 0.04–0.06)`, Y offset 8–16px, blur 32–48px; no harsh black shadows.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 开始备课 |
| Empty state heading | 还没有可展示的课堂内容 |
| Empty state body | 先从示例课程、课堂外壳或资源入口开始，完成基础结构后再接入真实数据。 |
| Error state | 页面外壳暂时无法加载。请刷新页面；如果仍失败，请返回工作台重试。 |
| Destructive confirmation | 离开课堂外壳：确认离开当前课堂预览？未保存的本地界面状态不会保留。 |

Copywriting constraints:
- All user-visible UI copy must be Simplified Chinese.
- Button labels must be verb + noun when action-oriented: `开始备课`, `进入课堂`, `继续学习`, `创建课程`, `上传资源`.
- Empty states must include one clear next step and must not mention implementation internals such as database, mock, seed, or placeholder to end users.
- Route shell labels for Phase 1: `首页`, `教师工作台`, `学生空间`, `课堂运行`, `课程中心`, `资源中心`, `管理后台`.

## Interaction Contracts

- **Route shell navigation:** active route uses a rounded-full tonal pill with primary accent text or gradient highlight; inactive routes use transparent/tonal hover only, no underline dividers.
- **Focus states:** keyboard focus must be visible with 2px ghost border or soft primary glow; do not rely on color-only changes.
- **Hover states:** use background tonal shift (`surface-container-low` ↔ `surface-container-lowest`) and tiny transform only if motion is reduced-safe; never add black drop shadows.
- **Glass surfaces:** floating nav, tooltips, dropdowns, and dialogs use `surface` at ~80% opacity with `backdrop-blur: 12px–20px`.
- **Responsive shells:** desktop uses persistent sidebars or split panes; mobile collapses into top glass nav + bottom/overflow navigation while preserving 44px touch targets.
- **Loading states:** use tonal skeleton blocks on the same surface tier as final content; no spinner-only full-page waits for route shells.
- **PPR/Suspense placeholders:** static shell remains visible; user-specific or live regions render localized skeleton/empty state copy without layout shift.
- **Destructive actions:** Phase 1 should avoid destructive behavior except leaving previews; if present, require a confirmation dialog styled as glass modal with destructive color reserved for the final confirm button.
