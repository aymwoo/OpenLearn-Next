<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Teacher UI / Server Action -> DAL | Untrusted action inputs cross into authorization and mutation logic. |
| Student EventSource / snapshot route -> DAL | A student may request another classroom session ID. |
| DAL -> SQLite | Versioned writes must preserve state integrity and event history. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Elevation of Privilege | `launchClassroomSession` | mitigate | Use `assertActiveTeacher`, school scope checks, course/class link checks, and published lesson checks before insert. |
| T-05-02-02 | Information Disclosure | `getClassroomSnapshotDTO` | mitigate | Authorize teacher or participant membership before returning sanitized snapshot DTO. |
| T-05-02-03 | Tampering | `changeClassroomActiveStep` / `changeClassroomMode` | mitigate | Require `expectedVersion`, conditional update by current version, and append-only event record. |
| T-05-02-04 | Repudiation | Control events | mitigate | Insert `classroomEvents` with actor, type, version, and payload for every launch/control/end action. |
| T-05-02-05 | Denial of Service | Snapshot reads | mitigate | Query by indexed `sessionId`, `studentId`, and `version`; return compact participant DTOs. |
| T-05-02-06 | Information Disclosure | Draft/submission preservation | mitigate | Control mutations never read or mutate task/quiz draft or append-only submission payloads. |
</threat_model>
