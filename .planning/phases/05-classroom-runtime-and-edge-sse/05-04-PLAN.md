<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/EventSource -> Edge SSE | Student may subscribe to an arbitrary session ID. |
| Edge SSE -> Node snapshot endpoint | Edge must not become the authorization or DB tier. |
| Snapshot endpoint -> DAL | Route parameters cross into protected snapshot reads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Information Disclosure | Edge SSE route | mitigate | Edge route emits only DTO-validated snapshot data fetched from authorized Node snapshot endpoint. |
| T-05-04-02 | Elevation of Privilege | Snapshot route | mitigate | Snapshot route delegates all authz to server-only classroom DAL. |
| T-05-04-03 | Denial of Service | SSE polling | mitigate | Poll every 2000 ms, emit compact snapshots only when version increases, and keepalive otherwise. |
| T-05-04-04 | Tampering | SSE payload | mitigate | Validate fetched JSON with `ClassroomSnapshotDTOSchema` before framing events. |
| T-05-04-05 | Information Disclosure | Edge imports | mitigate | Edge route must not import DB, Drizzle, DAL, or DB-backed Auth.js code. |
</threat_model>
