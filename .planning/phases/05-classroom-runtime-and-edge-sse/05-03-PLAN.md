<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form -> Server Action | Teacher-controlled inputs can be stale or tampered with. |
| DAL DTO -> Teacher UI | Teacher UI must render sanitized state without DB access. |
| Conflict result -> Client state | Preserved attempted action must not replay without confirmation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | `classroom-actions.ts` | mitigate | Validate every input with Zod schema and use `expectedVersion` for controls. |
| T-05-03-02 | Elevation of Privilege | `/classroom` UI | mitigate | Page loads DAL DTO only; UI never imports DB and actions call DAL authorization. |
| T-05-03-03 | Repudiation | Teacher conflict recovery | mitigate | Preserve attempted action visibly and require explicit confirmation after snapshot refresh. |
| T-05-03-04 | Information Disclosure | Roster UI | mitigate | Render sanitized participant DTOs only: names, connection state, step title, timestamps. |
| T-05-03-05 | Denial of Service | Control spam | mitigate | Disable controls during pending/stale states and allow only one pending action. |
</threat_model>
