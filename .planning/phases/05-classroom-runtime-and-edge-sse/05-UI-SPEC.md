# Phase 5 — UI Design Contract

> Visual and interaction contract for teacher live classroom control and student
> Edge SSE live-following states. Generated by gsd-ui-researcher, verified by
> gsd-ui-checker.

---

## Design System

Phase 5 must extend the existing manual Tailwind v4 design system from
`DESIGN.md` and the Phase 1 shell. The interface must keep the Luminous Academy
visual language: Lexend, Simplified Chinese copy, tonal surfaces, no 1px divider
lines, glass or gradient emphasis, and premium K-12 classroom calm.

| Property | Value |
|----------|-------|
| Tool | none — existing manual Tailwind v4 tokens |
| Preset | not applicable |
| Component library | Radix primitive patterns only where needed; no shadcn preset detected |
| Icon library | lucide-react, sparse semantic icons only |
| Font | Lexend via `next/font/google` and `--font-sans` |

Detected baseline:

- `components.json` is absent, so shadcn is not initialized for this project.
- `src/app/globals.css` defines surface, primary, tertiary, error, ambient shadow,
  radius, and spacing tokens.
- Existing `Button`, `Card`, and `Badge` primitives already enforce rounded,
  no-line, tonal UI patterns.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, live status dot spacing, compact metadata |
| sm | 8px | Compact element spacing, reconnect helper text gaps |
| md | 16px | Default element spacing, roster row internal gaps |
| lg | 24px | Control card padding, player state panels |
| xl | 32px | Teacher console column gaps, major surface breathing room |
| 2xl | 48px | Hero-to-controls separation on desktop |
| 3xl | 64px | Page-level spacing and large empty-state blocks |

Exceptions: Teacher step controls and student lock-mode controls must have a
minimum 44px hit target; primary classroom actions use the existing 48px
`Button` minimum height.

## Typography

Phase 5 uses exactly four text sizes and exactly two weights. Do not introduce
additional ad hoc text scales in live classroom surfaces.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading | 28px | 600 | 1.2 |
| Display | 36px | 600 | 1.1 |

Usage rules:

- Use Display only for the active lesson title or live-classroom empty state.
- Use Heading for `当前步骤`, `课堂模式`, `学生状态`, and recovery panels.
- Use Body for instructional content, mode explanations, and student-facing
  player messages.
- Use Label for timestamps, connection state, roster metadata, and badge text.

## Color

The classroom runtime UI must communicate live state without becoming alarmist.
Use surface changes and concise badges instead of divider lines.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f5f6f7` (`surface`) | Page background, calm live-classroom floor |
| Secondary (30%) | `#eff1f2` (`surface-container-low`) and `#ffffff` (`surface-container-lowest`) | Console panels, student player regions, roster cards, recovery panels |
| Accent (10%) | `#005da7` to `#68abff` gradient | Launch class CTA, active step badge, locked-mode indicator, SSE connected state, focused controls |
| Destructive | `#b31b25` | End session, discard stale control attempt, unrecoverable SSE error only |

Accent reserved for: `开始课堂`, `切换到此步骤`, current active step marker,
locked-follow badge, connected/live SSE indicator, focus-visible outlines, and
teacher recovery primary action. Do not use accent for every clickable roster
item or secondary navigation.

Semantic state colors:

- Success or stable: use `#386700` with `#a4fd4c` only for “已连接”, “已跟随”,
  and “状态已恢复”.
- Pending: use `primary-container/25` with primary text for “同步中”, “正在切换”,
  and optimistic lock-mode changes.
- Stale or conflict: use a warm tonal card with error text, not a full red page.

## Copywriting Contract

Copy must be Simplified Chinese, short, teacher-controlled, and reassuring. It
must describe the classroom state and the next safe action.

| Element | Copy |
|---------|------|
| Primary CTA | 开始课堂 |
| Empty state heading | 还没有正在运行的课堂 |
| Empty state body | 选择一个已发布课时并添加学生名单后，就可以开始实时课堂。 |
| Error state | 课堂状态没有同步成功。请刷新课堂快照，确认当前步骤后再继续控课。 |
| Destructive confirmation | 结束课堂: 结束后学生将停止接收实时跟随更新，课堂记录会保留。确认结束这节课？ |

Additional required live-state copy:

|-------|------|

| Teacher active-step pending | 正在切换到“{stepTitle}”。 |

## Interaction contract

Phase 5 has two primary surfaces: the teacher classroom console and the student
live player. Both surfaces must treat SQLite state as durable source of truth
and Edge SSE as the live update channel.

### Teacher classroom console

- Layout: use a desktop-first two-column console: left column for lesson title,
  active-step control, and lock mode; right column for roster and live state.
  On small screens, show a tonal notice: “建议使用桌面端控课，当前为可读预览”.
- Launch: `开始课堂` creates a session from a published lesson and roster. During
  pending state, disable the CTA and show “正在创建课堂，请稍候。”
- Active step: each step control must show index, title, type, and state. The
  active step uses a white `surface-container-lowest` pill or card with ambient
  shadow and primary accent marker. Inactive steps use `surface-container-low`.
- Optimistic change: after “切换到此步骤”, immediately mark the target step as
  “同步中” with primary-container tone. Replace with “当前步骤” only after the
  Server Action succeeds and the SSE or refreshed snapshot confirms the version.
- Lock mode: present two rounded options: `锁定跟随` and `自由浏览`. Locked mode
  must explain “学生端跟随教师当前步骤”; unlocked mode must explain “学生可回看已开放步骤”.
- Conflict recovery: when session version is stale, block further step or mode
  actions, show the latest-known update time, and provide one primary action
  “刷新课堂快照”. Preserve the teacher’s attempted action in copy, but do not
  retry automatically.
- Roster: show participant cards with name, connection state, current step, and
  last-seen timestamp. Separate rows by whitespace and tonal backgrounds only.

### Student live player

- Initial load: render cached lesson shell first, then stream personal progress
  and classroom runtime state under Suspense. Do not show raw loading spinners
  without context; use skeleton cards with “正在读取课堂状态”.
- SSE connected: show a small glass status chip “课堂已连接” near the player header.
- Reconnecting: keep the current content visible, show “正在重新连接课堂，会先显示最近一次课堂状态”,
  and avoid jumping steps until snapshot reconciliation completes.
- Late join: show the durable snapshot state first. If locked, navigate to the
  active teacher step and show “已恢复课堂状态，你现在看到的是最新步骤。”
- Locked mode: disable independent step navigation, keep visible controls but
  tonal-muted, and provide an explanatory inline note rather than hiding steps.
- Unlocked mode: enable permitted navigation using the existing Phase 4 player
  behavior and keep the active teacher step visible as a soft recommendation.
- SSE error: show a non-destructive recovery panel with “重新连接课堂”. Do not lose
  task or quiz draft input while the stream reconnects.

### Accessibility and motion

- All controls must be keyboard reachable with the existing 2px primary
  focus-visible outline.
- Live status changes must be announced through an `aria-live="polite"` region.
  Conflict and destructive confirmations must use assertive dialog semantics.
- Motion is limited to 120–180ms tonal fades or slight translate transitions.
  Do not animate rapid roster updates in a way that distracts during teaching.
