| Classroom runtime -> Navigation | Runtime state can disable navigation but must not mutate progress or submissions. |
| Reconnect UI -> Draft inputs | Reconnect state must not remount or discard task/quiz input. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
