<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Drizzle schema -> DAL | Schema defines classroom ownership and cascade boundaries that DAL must enforce. |
| DTO -> client/UI | DTOs prevent raw session, participant, account, and internal row leakage. |
| Runtime DTO -> student navigation | Lock state controls navigation but must not block current-step submissions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Tampering | `classroomSessions.version` | mitigate | Store durable integer `version` and require later `expectedVersion` mutations. |
| T-05-01-02 | Information Disclosure | `ClassroomSnapshotDTOSchema` | mitigate | DTO contains sanitized participant and session fields only; no raw auth/account/password/provider fields. |
| T-05-01-03 | Denial of Service | `classroomEvents` | mitigate | Add `(sessionId, version)` and `(sessionId, createdAt)` indexes so polling and snapshot reads do not scan the full event table. |
| T-05-01-04 | Repudiation | `classroomEvents.actorId` | mitigate | Append actor ID and event payload for launch, step, lock, refresh, and end actions. |
| T-05-01-05 | Information Disclosure | Classroom participant rows | mitigate | Cascade participants from sessions and users; later DAL checks roster membership before exposing snapshots. |
</threat_model>
