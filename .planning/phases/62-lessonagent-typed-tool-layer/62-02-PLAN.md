## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM/调用方 → tool inputSchema | 不可信意图与参数跨入工具层；非法 payload 在边界处必须被拒 |
| tool execute → Phase 61 facade | 生成请求跨入受控 AI 通道；tool 不得绕过 facade 直连 provider/apiKey |
| server/ai/tools → client/edge/plugin | server-only 资产绝不可被低信任执行面 import |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-62-03 | Spoofing | teacherId 限流/授权维度 | mitigate | teacherId 经 factory 闭包注入，排除出 LLM 可控 inputSchema；单测断言 inputSchema 无 teacherId 键（Task 1 Test 3）|
| T-62-04 | Tampering / Elevation | tool 输入 payload | mitigate | inputSchema Zod 边界校验，非法 lessonId/stepType 在此被拒（Task 1 Test 1 / AGENT-01）|
| T-62-05 | Information Disclosure | provider apiKey / DB 句柄 | mitigate | tool 仅 import facade 窄 barrel（无 config/registry）+ 只读 DAL；no-leak A 组静态证明 client/edge/plugin 不 import tools（Task 1 Test 5 / AGENT-02）|
