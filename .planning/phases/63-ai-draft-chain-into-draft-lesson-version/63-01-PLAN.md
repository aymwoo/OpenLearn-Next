```typescript
export const draftLessonVersions = sqliteTable(
  "draftLessonVersion",
  {
    id: text("id").primaryKey().$defaultFn(() => crypto.randomUUID()),
    lessonId: text("lessonId").notNull()
      .references(() => lessons.id, { onDelete: "cascade" }),       // AGENTS.md: FK 必 cascade
    version: integer("version").notNull(),                          // 同 lessonId 维度 max+1 自增
    snapshotJson: text("snapshotJson", { mode: "json" }).notNull(), // 内联整课 step 快照（A3：不建子表）
    source: text("source", { enum: ["ai", "human", "ai_edited"] })
      .notNull().default("ai"),                                     // D-04：本相位只写 "ai"，三值全枚举为 Phase 64 预留
    sourceCommandId: text("sourceCommandId").notNull(),             // D-04：回链产出命令 (= command.id) 做 provenance；非空以入唯一约束
    createdById: text("createdById").notNull()
      .references(() => users.id, { onDelete: "cascade" }),         // 对应 publish 的 publishedById
    createdAt: integer("createdAt", { mode: "timestamp_ms" }).$defaultFn(() => new Date()),
  },
  (table) => [
    index("draftLessonVersions_lessonId_version_idx").on(table.lessonId, table.version),
    uniqueIndex("draftLessonVersions_idempotency_unique").on(table.lessonId, table.sourceCommandId),
  ]
);
```

关键约束（不得偏离）：
- **`sourceCommandId` 非空**：bus 对同一 `dedupeKey` 复用同一 command 记录（同 command.id），pending-崩溃-重放时第二次 INSERT 携带相同 `sourceCommandId` → 撞 `draftLessonVersions_idempotency_unique` 兜底（DRAFT-02 / Pitfall 1）。非空规避 SQLite「多 NULL 不冲突」语义。
- **内联 `snapshotJson`**（A3 灰区拍板）：不建 `draftLessonStepVersions` 子表，保持单表单 INSERT 原子性（RESEARCH Pitfall 3）。
- 不新增任何对 `lessons`/`lessonSteps` 的列或反向引用（D-01：draft 永不触碰 live）。
- `index`/`uniqueIndex`/`sqliteTable`/`text`/`integer` 均为 schema.ts 现有导入，无需改 import。
