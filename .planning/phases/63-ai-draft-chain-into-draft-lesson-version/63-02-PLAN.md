```typescript
export async function persistDraftLessonVersion(input: {
  lessonId: string;
  steps: LessonStepPayload[];      // 来自 lessonStepPayloadSchema 推断
  sourceCommandId: string;          // command.id，provenance + 表层幂等键
  createdById: string;              // 起草教师 id（对应表 createdById FK→users，handler 闭包注入，非 payload）
}): Promise<{ draftVersionId: string; version: number; stepCount: number }> {
  // 1) 取下一 version：select max(version) from draftLessonVersions where lessonId = input.lessonId
  //    无行 → 1，否则 max + 1（仿 publishLesson 取版本号写法）
  // 2) 单条原子 INSERT（A3 内联快照，不写子表）：
  //    db.insert(draftLessonVersions).values({
  //      lessonId, version, source: "ai",
  //      sourceCommandId: input.sourceCommandId,
  //      createdById: input.createdById,
  //      snapshotJson: JSON.stringify({ steps: input.steps }),
  //    }).returning(...)
  // 3) 返回 { draftVersionId, version, stepCount: input.steps.length }
  //    绝不 insert/update lessons 或 lessonSteps
}
```
注：`createdById` 来自 Plan 01 表的 notNull FK 列（对应 publish 的 `publishedById`），由 handler 从已授权 teacher 注入，**不**取自 command payload。

约束（不变式，DRAFT-01）：
- **只** `insert(draftLessonVersions)`；函数体内不得出现 `lessonSteps` / `lessons` 的 insert/update。
- `source` 硬编码 `"ai"`（本相位只写 'ai'，D-04）；不从入参接受 source，避免越权写其它来源。
- 不在 DAL 调用 `lesson.draft.run` 或任何 AI 生成（persist 与 run 解耦，D-05）。
- 唯一约束 `(lessonId, sourceCommandId)` 由表层兜底；DAL 不吞约束冲突——冲突向上抛，由 Plan 04 handler 的幂等策略处理（dedupe + 约束）。

import `LessonStepPayload` 类型（`@/lib/dto/lesson-authoring` 的 `z.infer<typeof lessonStepPayloadSchema>`，若未导出则在 dto 文件补 `export type`）。
