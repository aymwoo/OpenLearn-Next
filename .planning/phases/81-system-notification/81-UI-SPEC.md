## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge offset positioning |
| sm | 8px | Compact element spacing, notification item internal gap |
| md | 16px | Default element spacing, list item padding |
| lg | 24px | Section padding, dropdown panel padding |
| xl | 32px | Layout gaps, page content padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Badge dot: 8px x 8px (w-2 h-2) absolute positioned at top-right of bell icon, offset -2px/-2px — follows existing teacher layout pattern
- Icon-only touch target: 40px (p-2.5 on 20px icon) — follows existing headerActions button pattern
- Notification item min-height: 56px — ensures comfortable touch target on mobile

**Source:** 8-point scale pre-populated from DESIGN.md + codebase scan of existing teacher layout spacing patterns.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `surface` (#f5f7f9) | Page background (`/notifications` page) |
| Secondary (30%) | `surface-container-lowest` (#ffffff) | Notification list items, dropdown panel, cards |
| Accent (10%) | `primary` (#0050d4) | "标记已读" action text, "查看全部" link, selected state indicator |
| Destructive | `error` (#b31b25) | Only unused in this phase — no destructive notification actions defined |

Accent reserved for: "标记全部已读" button, "查看全部" link hover state, unread indicator dot (primary solid fill replacing current red).

**Surface layering (per DESIGN.md "No-Line" rule):**
- Dropdown panel: `surface-container-lowest` (#ffffff) with `shadow-lg` + `backdrop-blur` (no border)
- Notification list items: `surface-container-lowest` on page, `surface-container-low` on hover
- Unread items: 4px `primary` left edge dot (inside item, 4px x 4px circle at padding-start)
- Badge counter: `primary` background + `on-primary` (#ffffff) text, 16px height pill
- Relative time label: `on-surface-variant` (#595c5e)
- Unread count: `on-surface-variant` for number, `primary` for badge dot

**Bell icon states:**
- Default: `on-surface-variant` (#595c5e)
- Has unread: `primary` (#0050d4) — icon itself gets primary color (not just badge)
- Hover: `on-surface` (#2c2f31)

**Source:** DESIGN.md 60/30/10 split + globals.css token scan + existing teacher layout pattern analysis.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "标记已读" (notification center page, per-item action) |
| Secondary CTA | "查看全部" (dropdown footer link → /notifications) |
| Empty state heading | "暂无通知" |
| Empty state body | "系统通知将在此处显示" |
| Error state heading | "加载失败" |
| Error state body | "通知暂时无法加载，请稍后重试" |
| Destructive confirmation | Not applicable — Phase 81 has no user-initiated destructive actions |
| Badge (has unread) | Unread count number (e.g., "3") |
| Badge (empty / 0 unread) | Hide badge entirely |
| Dropdown heading | "最近通知" |
| Page heading | "通知中心" |
| "全部已读" button | "全部标为已读" |
| Relative time | "刚刚" / "N分钟前" / "N小时前" / "N天前" |

**Action semantics:**
- "标记已读" → single notification read (mutation: `POST /api/notification/mark-read { notificationId }`)
- "全部标为已读" → batch mark all read (mutation: `POST /api/notification/mark-read { markAll: true }`)
- 点击单条通知 → mark as read + 可选导航（当前 phase 不实现深度链接导航，仅标记已读）

**Source:** CONTEXT.md D-01 dropdown + page decision; NOTIF-02/03 requirements; DESIGN.md Chinese UI requirement.

## Interaction Contract

### Bell Icon + Badge (global header)

| State | Visual | Behavior |
|-------|--------|----------|
| Loading | Skeleton pulse on badge area (8x8 px) | Initial page load before first `/api/notification/unread-count` response |
| No unread | Bell icon `on-surface-variant`, no badge | Default state. Tooltip: "通知" |
| Has unread (1-9) | Bell icon `primary`, badge pill `primary` bg with count number | Single-digit count shown in 16px pill |
| Has unread (10+) | Bell icon `primary`, badge pill `primary` bg with "9+" | Overflow capped at 9+ |
| Hover (any) | Bell icon `on-surface`, background `surface-container-low` | Cursor: pointer. Tooltip hidden on hover. |
| Click (open) | Dropdown appears, bell stays in hover state | Toggle dropdown. Click again or click outside to close. |
| Polling update | Badge number animates (fade transition 200ms) | Every 10s: `GET /api/notification/unread-count` → update badge |

**Source:** CONTEXT.md D-01 (bell icon + badge + dropdown); Claude's Discretion (polling 10s, badge design).

### Dropdown Panel

| Property | Value |
|----------|-------|
| Width | 360px |
| Max height | 480px (scroll if overflow) |
| Position | Right-aligned below bell icon, 8px gap |
| Animation | Scale + fade in (origin top-right), 150ms ease-out |
| Dismiss | Click outside, press Escape, or click bell again |
| Items shown | 最近 5 条通知（倒序，按 createdAt DESC） |
| Footer | "查看全部" link → `/notifications` |

**Dropdown item layout (each, 5 items max):**
- Height: min 56px, padding: md (16px)
- Left: notificationType icon (optional, 40px circle `surface-container-low`)
- Center column: title (14px medium, max 2 lines truncated) + body (12px regular, max 1 line truncated)
- Right: relative time label (11px, `on-surface-variant`)
- Unread indicator: 8px `primary` dot at top-left of item (or left border accent)
- Click on item: mark as read + dismiss dropdown (no navigation)

**Source:** CONTEXT.md D-01 (dropdown 5 items + "查看全部" link); Claude's Discretion (position left of avatar).

### `/notifications` Page

| Property | Value |
|----------|-------|
| Route | `/notifications` (no route group wrapper — uses shared page-level layout) |
| Layout | Centered content, max-width 680px |
| Header | "通知中心" heading + "全部标为已读" button (secondary style). Button disabled when no unread notifications. |
| List | Cursor-based pagination, 20 items per page |
| Item | Same structure as dropdown item, full width, with hover state |
| Empty | Centered illustration/icon placeholder + "暂无通知" + body text |
| Loading | Skeleton list (3 items with shimmer) |
| Error | Error message card with "重试" button |

**Pagination:**
- "加载更多" button at bottom of list (loads next 20 items via cursor)
- No page numbers — infinite scroll pattern via "加载更多"

**Source:** CONTEXT.md D-01 (independent page); NOTIF-02 (pagination 20 per page); REQUIREMENTS.md NOTIF-02/03/04.

### Polling Pattern

| Aspect | Value |
|--------|-------|
| Interval | 10 seconds (aligns with homework-submission-list pattern) |
| Endpoint | `GET /api/notification/unread-count` |
| Auth | Auth.js session cookie |
| Stop condition | Document hidden (Page Visibility API) — pause polling, resume on visible |
| Debounce | Skip poll if a mutation (mark-read) is in-flight |

**Source:** CONTEXT.md Claude's Discretion (10s polling).

## Copywriting Guidelines (Contract Extensions)

### Notification Body Truncation

- Dropdown: body text truncated to 1 line via CSS `line-clamp-1` (max ~40 characters visible)
- List page: body text truncated to 2 lines via CSS `line-clamp-2`
- No "展开" action in this phase — full body visible on click is deferred (NOTIF-N04)

### Relative Time Format (Simplified Chinese)

Built as a simple utility in `src/lib/relative-time.ts`:

```
< 1 minute:     "刚刚"
1-59 minutes:   "N分钟前"
1-23 hours:     "N小时前"
1-30 days:      "N天前"
> 30 days:      "YYYY-MM-DD" (date only)
```

**Source:** Claude's Discretion — utility implementation, aligns with Chinese UI convention.
