<task type="auto">
  <name>Task 2: Initialize Drizzle and define SQLite Schema</name>
  <files>src/db/schema.ts, src/db/index.ts, drizzle.config.ts</files>
  <action>
Create `src/db/schema.ts`. Define standard Auth.js v5 tables: `users`, `accounts`, `sessions`, `verificationTokens`. 
Also define OpenLearn Next specific tables: 
- `schools` (id, name, createdAt).
- `memberships` (id, userId, schoolId, role, status). `userId` must reference `users.id` with `.onDelete("cascade")`. `schoolId` references `schools.id` with cascade. `role` should be a text column that will hold enums like 'admin', 'teacher', 'student', 'parent', 'developer', 'ai_agent'.
- `classes` (id, schoolId, name).
- `classMembers` (id, classId, userId, role).
Use `drizzle-orm/sqlite-core`. Ensure `onDelete: "cascade"` is present on all foreign keys pointing to parent records.
Add `.index()` for high-frequency reads (e.g., index `userId` in `memberships`).

Create `src/db/index.ts` that initializes the libSQL client and Drizzle:
`import { drizzle } from 'drizzle-orm/libsql';`
`import { createClient } from '@libsql/client';`
Initialize with `url: process.env.DB_FILE_NAME || "file:local.db"`.

Create `drizzle.config.ts` using `defineConfig` from `drizzle-kit`, pointing to `./src/db/schema.ts`, using dialect `sqlite`, and `dbCredentials.url` from `process.env.DB_FILE_NAME || "file:local.db"`.
  </action>
  <verify>
    <automated>grep -q "onDelete: .cascade." src/db/schema.ts</automated>
  </verify>
  <done>Schema file exists containing Auth.js tables and memberships with cascade deletes.</done>
</task>
