## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `process.env`（Node）→ provider 装配 | apiKey/baseURL 经 config.ts 单点读取，是 PROV-02 的唯一入口；server-only 编译期阻止进入 client bundle |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
