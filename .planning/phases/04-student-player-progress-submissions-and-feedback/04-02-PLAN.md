## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student session → DAL | Authenticated student identity scopes dashboard, player, progress, and submissions. |
| Teacher session → DAL | Authenticated teacher identity scopes review and feedback. |
| Published snapshot JSON → DTO | Stored lesson payload JSON is parsed before UI exposure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Spoofing | `assertActiveStudent` | mitigate | Require `getCurrentUserDTO()` plus active `student` membership before student reads/writes. |
| T-04-02-02 | Tampering | `submitTaskAttempt` / `submitQuizAttempt` | mitigate | Use `db.transaction` to clear prior latest and insert append-only latest attempt. |
| T-04-02-03 | Information Disclosure | `getStudentPlayerDTO` | mitigate | Read only `publishedLessonVersions.snapshotJson`; return unified `课时暂不可学习` for missing/unauthorized/unpublished lessons. |
| T-04-02-04 | Elevation of Privilege | `getTeacherLessonReviewDTO` | mitigate | Reuse `assertActiveTeacher()` and scoped lesson/course checks before review or feedback. |
</threat_model>
