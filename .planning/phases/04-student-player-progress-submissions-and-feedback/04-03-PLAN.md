<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form → Server Action | Untrusted progress, submission, quiz, and feedback input crosses into server code. |
| Server Action → DAL | Validated inputs cross into authorized persistence methods. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Tampering | `submitTaskAttemptAction` | mitigate | Validate with `SubmitTaskInputSchema.safeParse` before DAL write. |
| T-04-03-02 | Repudiation | `submitQuizAttemptAction` | mitigate | Return deterministic success/failure ActionResult and rely on append-only DAL attempt rows. |
| T-04-03-03 | Information Disclosure | `learning-actions.ts` | mitigate | Do not import DB/schema or return raw errors; map validation/failure messages to Chinese safe copy. |
| T-04-03-04 | Denial of Service | `sendAttemptFeedbackAction` | mitigate | Enforce `FeedbackInputSchema` 200-character cap before persistence. |
</threat_model>
