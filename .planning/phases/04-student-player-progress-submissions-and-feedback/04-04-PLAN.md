<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Route → UI props | Server-loaded sanitized DTOs cross into React components. |
| Client component → Server Action | Student draft answers and quiz selections cross from browser to server actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | Information Disclosure | `StudentDashboardSurface` / `PlayerSurface` | mitigate | Components receive DTO props only and must not import `@/db`, schema, or demo draft data. |
| T-04-04-02 | Tampering | `TaskStepCard` / `QuizStepCard` | mitigate | Client calls Server Actions; authoritative progress/attempt state remains server-side. |
| T-04-04-03 | Repudiation | submission UI | mitigate | UI displays latest attempt timestamp/history from server DTO instead of local-only state. |
</threat_model>
