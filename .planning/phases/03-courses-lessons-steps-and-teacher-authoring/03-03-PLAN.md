<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Server Action | Untrusted form/object input crosses into server mutation code. |
| Server Action -> DAL | Validated inputs invoke privileged authoring mutations. |
| Mutation -> Cache | Persistent writes invalidate explicit Next.js cache tags. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Tampering | Server Action inputs | mitigate | Parse every action input with Zod before calling DAL. |
| T-03-09 | Repudiation | conflict handling | mitigate | Return deterministic `CONFLICT` result for stale writes so teacher sees overwrite risk. |
| T-03-10 | Information Disclosure | action returns | mitigate | Return DTO-safe DAL results only; never expose raw DB rows. |
| T-03-11 | Denial of Service | stale cache | mitigate | Call `updateTag()` for course, lesson, and steps after successful writes. |
</threat_model>
