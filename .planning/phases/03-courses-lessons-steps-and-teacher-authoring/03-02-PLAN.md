<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auth session -> DAL | Current session identity becomes teacher-scoped data access. |
| DAL -> UI/Actions | Raw database rows become sanitized DTOs and mutation results. |
| Draft -> Published version | Mutable authoring state becomes student/classroom-readable immutable snapshot. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Spoofing | `assertActiveTeacher` | mitigate | Require current authenticated user and active `teacher` membership from Phase 2 DAL. |
| T-03-05 | Elevation of Privilege | authoring mutations | mitigate | Verify school/course/lesson scope before every write. |
| T-03-06 | Information Disclosure | DAL returns | mitigate | Parse through DTO schemas before data reaches UI or Server Actions. |
| T-03-07 | Tampering | `publishLesson` | mitigate | Build published snapshot from current ordered non-archived draft steps inside DAL. |
</threat_model>
