<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| classroom tab → homework DAL | 教师通过 /classroom 访问学生提交，经 auth split 鉴权 |
| teacher grade → grades 表 | 分数/评语经 submitGradeAction → append-only 写入，保留批改历史 |
| student submission list → teacher view | 按 classroomSession 过滤，不跨 session 泄露 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-75-10 | Elevation | 学生访问批改面板 | mitigate | classroom tab + homework DAL 检查 session.role==="teacher" |
| T-75-11 | Tampering | 分数篡改 | mitigate | grades 表 append-only 保留完整历史，每次修改新插入行 |
| T-75-12 | Information Disclosure | 跨 session 提交泄露 | mitigate | getHomeworkSubmissions 按 classroomSession scope 过滤 |
| T-75-13 | Denial of Service | 大量提交导致列表渲染卡顿 | mitigate | 前端分页/虚拟滚动（若提交数 > 50），初始加载 limit 50 |
</threat_model>
