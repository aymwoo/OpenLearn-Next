<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upgrade backfill→verify→cutover | 三阶段迁移隔离，verify 失败则回滚 cutover |
| uninstall retain→cleanup | cleanup 需确认 token，防止误删数据 |
| 同 pluginKey 重装 | 重装后 pluginId 相同但数据从零开始，不泄露已删除数据 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-75-14 | Tampering | upgrade 迁移数据完整性 | mitigate | backfill→verify→cutover 三阶段 + 零丢失断言 |
| T-75-15 | Elevation | uninstall cleanup 越权 | mitigate | cleanup 需 confirm token + session.role 验证 |
| T-75-16 | Information Disclosure | 重装后数据泄露 | mitigate | cleanup 彻底删除三表数据（DELETE WHERE pluginId） |
| T-75-17 | Denial of Service | 迁移冲突 | mitigate | migration-first 流程 + Drizzle journal 连续性校验 |
</threat_model>
