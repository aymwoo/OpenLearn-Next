## Typography

**Font:** Lexend (loaded via `next/font/google` — project standard per DESIGN.md §4).

**Chinese fallback:** Lexend includes Latin glyphs; Simplified Chinese characters render via system fallback (`--font-lexend` CSS variable configured in `src/app/globals.css`).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (0.875rem) | 400 (regular) | 1.5 | Secondary text, helper copy, dashboard fine-print (e.g. "最近 20 条作答") |
| Label | 14px (0.875rem) | 500 (medium) | 1.4 | Section labels, metric labels, tab triggers ("作答实时", "选项分布") |
| Heading | 24px (1.5rem) | 600 (semibold) | 1.2 | Section titles ("作答实时监控", "课堂回顾统计") |
| Display | 2rem–2.5rem | 600 (semibold) | 1.05–1.08 | Phase does NOT introduce new display text — existing control panel `h2` at `text-[2rem] sm:text-[2.5rem]` is reused |

**Weights:** 400 (regular) + 600 (semibold). No additional weights needed for this phase.

**Source:** DESIGN.md §4 specifies Lexend with Body at 1rem (converted to 14px for dense dashboard data) and Display at 2.5rem for headings. Existing `ClassroomControlPanel` uses `text-2xl font-semibold` (24px/600) for section headings and `text-sm` (14px) for metric labels — dashboard tab follows identical conventions.

**Line height rule:** Body 1.5 for readability of Chinese text; Heading 1.2 for compact titles; Label 1.4 for tab triggers and action labels.

## Color

All colors defined via CSS variables from shadcn `mist` base. Semantic surface tokens from DESIGN.md §3:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--surface)` — #f5f7f9 | Application base background, main content area backdrop |
| Secondary (30%) | `var(--surface-container-low)` — #eef1f3 | Cards, tab panels, aggregation stat blocks, sidebar sections |
| Accent (10%) | `var(--primary)` — #0050d4 | Active tab indicator, selected question highlight ring, critical metric counters, "作答实时" tab label when active |
| Destructive | `var(--destructive)` — #ef4444 | Destructive actions only — **not applicable to this phase** (dashboard is read-only; no destructive actions exist in dashboard or recap) |

**Accent reserved for:**
1. Active tab underline/indicator (shadcn `TabsTrigger` active state)
2. Question row highlight when selected/hovered (e.g. clicking a question in aggregation panel)
3. Live counter badge (e.g. "12 人已提交" accent badge)
4. Percentage bar fill in option distribution (e.g. 45% → primary fill bar)
5. Focus ring on interactive dashboard elements (e.g. N-value selector dropdown)

**NOT accent:** Regular metric text, option labels, student names, tab triggers (inactive state), stat table rows — these use `on-surface` (#2c2f31) or `on-surface-variant` (#595c5e).

**Gradient CTA rule (DESIGN.md §3.3):** Primary CTA buttons use `bg-linear-135 from-primary to-primary-container text-on-primary` with `rounded-[1.35rem]`. This phase's dashboard is read-only and has **zero primary CTAs** — no write actions. The existing "结束课堂" and "锁定跟随" buttons in the control panel remain unchanged.

**No-line rule (DESIGN.md §3.2):** Absolutely NO `border`, `border-b`, `border-r`, or 1px dividers. Section separation uses:
- Background shift: `surface-container-lowest` cards on `surface-container-low` panels
- Rounded corners: `rounded-[1.1rem]` to `rounded-[1.6rem]` create visual separation
- Tonal gaps: whitespace (`gap-3`, `gap-5`) instead of lines

**Tinted shadow pattern:** Use `shadow-ambient` (already defined in project) — `rgba(44, 47, 49, 0.06)` — for card elevation. Never use dark/black shadows.

## Layout Contract: Dashboard Tab Integration

### Integration Point: `ClassroomControlPanel`

The live answer dashboard is integrated as a **sibling tab** within the existing `ClassroomControlPanel`, not a separate page or route.

```
ClassroomControlPanel (existing)
├── <Tabs defaultValue="control">
│   ├── <TabsList>
│   │   ├── <TabsTrigger value="control">课堂控制</TabsTrigger>
│   │   └── <TabsTrigger value="live-answers">作答实时</TabsTrigger>
│   ├── <TabsContent value="control">
│   │   └── [existing control panel content — unchanged]
│   └── <TabsContent value="live-answers">
│       └── <LiveAnswerDashboardSurface />  ← NEW
```

**Tabs styling:**
- `TabsList`: `bg-surface-container-lowest rounded-[1.1rem] p-1` — matches existing tonal surface card style
- `TabsTrigger` (active): `bg-surface text-primary font-semibold rounded-[1rem]` — tonal surface shift, no border
- `TabsTrigger` (inactive): `text-on-surface-variant hover:bg-surface-container-low rounded-[1rem]` — low-emphasis, no border
- `TabsContent`: `mt-5` — separation via whitespace, not border

**No background color change between tabs** — the whole control panel maintains `bg-surface` background. Only the `TabsList` and `TabsTrigger` use tonal surface shifts to indicate active state.

### Dashboard Surface Internal Layout

```
<LiveAnswerDashboardSurface>
├── Status bar: live connection indicator + student count + auto-refresh timestamp
├── <Tabs value={selectedView}>
│   ├── <TabsTrigger value="aggregation">按题分布</TabsTrigger>
│   └── <TabsTrigger value="recent-stream">作答流水</TabsTrigger>
├── <TabsContent value="aggregation">
│   ├── Question selector (horizontal scrollable chip list)
│   │   └── Chip per question: question title + questionType badge
│   └── <QuestionAggregationPanel>
│       ├── single_choice / multi_choice / true_false: bar chart (option → count + %)
│       ├── fill_blank: <FillBlankTopAnswers /> (top N most frequent answers)
│       └── ordering: sequence distribution (top orderings + count)
├── <TabsContent value="recent-stream">
│   ├── N-value selector (5 | 20 | 50) — inline button group
│   └── <RecentAnswersStream>
│       └── List of submission entries: question title, student (or "匿名"), answer preview, relative timestamp
```

**Spacing:**
- Dashboard section padding: `p-5` (20px) inside `Card` container
- Question chip gap: `gap-2` (8px)
- Option bar gap: `gap-3` (12px) between bars
- Recent stream entry padding: `px-4 py-3` (16px horizontal, 12px vertical)

### Visual Elements Per Question Type

| Question Type | Aggregation Display | Empty State |
|---------------|---------------------|-------------|
| `single_choice` | Horizontal bar chart: option label → count + percentage bar (primary fill) | "暂无单选作答" |
| `multi_choice` | Horizontal bar chart: each option counted independently (student can select multiple) → count + percentage of selecting students | "暂无多选作答" |
| `true_false` | Two-bar comparison: "正确" vs "错误" → count + percentage | "暂无判断作答" |
| `fill_blank` | Top answers leaderboard: rank number → answer text (truncated to 40 chars) → count | "暂无填空作答" |
| `ordering` | Top sequences: ordered array preview (truncated option labels) → count of students who chose this exact sequence | "暂无排序作答" |

**Percentage bar styling:**
- Bar background: `bg-primary/20` (20% opacity accent)
- Bar fill: `bg-primary` (solid accent)
- Bar height: `h-8` (32px)
- Bar rounded: `rounded-[0.6rem]`
- Label position: inside bar, right-aligned for large percentages; outside bar for small percentages
- No 1px border on bars (no-line rule)

## Interaction States

### Dashboard Tab — State Machine

| State | Trigger | Visual | Recovery |
|-------|---------|--------|----------|
| **connected** | WS connection established, receiving events | Green `Activity` icon, "实时连接正常" label, events flow into aggregation | (normal state) |
| **disconnected** | WS close/timeout | Yellow `AlertCircle` icon, "连接断开，正在重连…" banner at top of dashboard | Auto-reconnect via `subscribeClassroomSocket` retry logic |
| **reconnecting** | Auto-retry in progress | Pulsing yellow indicator, aggregation frozen (last known state), recent stream shows "重连中…" | Successful reconnect → transition to **connected** |
| **empty** | Connected but zero answers yet | Empty state copy (see Copywriting section), `Circle` icon, no aggregation/stream visible | First answer received → transition to **connected** with data |
| **session ended** | `snapshot.status !== 'live'` | Overlay: "课堂已结束" message with link to recap | User navigates to recap or back to classroom list |
| **error** | Unrecoverable WS error | Red `AlertCircle` icon, error state copy (see Copywriting section), "刷新页面" button | User clicks "刷新页面" → page reload |

### Question Aggregation — Interaction

| Interaction | Behavior |
|-------------|----------|
| Click question chip | Highlight chip (primary ring), switch aggregation panel to that question's stats |
| Hover option bar | Slight background brightening (`hover:bg-primary/25`), tooltip with exact count |
| Resize window | Bars reflow responsively; labels collapse to icon-only on < 640px |
| Real-time update (new answer) | Corresponding bar animates width change (CSS `transition: width 200ms ease`); count number increments with subtle scale pulse |

### Recent Stream — Interaction

| Interaction | Behavior |
|-------------|----------|
| Scroll stream | New entries appear at top; auto-scroll follows new entries if user is at top |
| Click N-value (5/20/50) | Stream resizes; selected value gets `bg-primary text-white` (active state) |
| Hover stream entry | Row background shifts to `bg-surface-container-low` (tonal hover, no border) |
| Freeze scroll | If user scrolls up manually, auto-scroll pauses (prevents disorientation); "↓ 新作答" float button appears |

## Accessibility Requirements

| Requirement | Implementation |
|-------------|---------------|
| Tab navigation | `<Tabs>` uses Radix roving tabindex pattern — keyboard navigable with ArrowLeft/ArrowRight |
| Color contrast | `on-surface` (#2c2f31) on `surface` (#f5f7f9) = 12.3:1 ratio (WCAG AAA); `on-surface-variant` (#595c5e) on `surface-container-low` (#eef1f3) = 5.8:1 (WCAG AA) |
| Screen reader | All metric values have `aria-label` (e.g. `aria-label="选项A：12人，45%"`); WS connection status has `aria-live="polite"` region; empty/error states are `role="status"` |
| Focus indicators | All interactive elements (question chips, N-value buttons, tab triggers) have visible focus ring using `ring-primary/50` |
| Reduced motion | Percentage bar width transitions respect `prefers-reduced-motion` — disable animation when set |
