<objective>
把 Plan 73-01 暴露的 `quiz.answer.received` hook 接入 v2.2 `classroom-ws` 通路,推送到教师端 `/classroom` 控制室的新增「作答实时」sibling tab。Tab 是只读、零写 Server Action 的 RSC + 客户端 Zustand 聚合;WS 通路在 `REDIS_URL` 存在/缺失两种 env 下行为等价(contract test 覆盖)。所有写操作继续走 v4.0 command-bus 路径(D-72.1-09)。

Purpose: 让老师在课堂进行时能实时看到全班作答进度与选项分布,无需轮询、不污染写路径。
Output: WS 事件 schema + teacher-only 通道 + 可选 Redis fanout + 教师控制室 live tab + Zustand 客户端聚合 + 零写姿势守卫。
</objective>
