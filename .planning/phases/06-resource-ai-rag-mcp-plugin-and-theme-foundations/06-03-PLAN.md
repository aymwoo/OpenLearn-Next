## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent proposal input -> DAL | Untrusted structured output metadata crosses into persistent proposals. |
| Retrieval preview -> filter helper | Scope inputs become Qdrant-ready filter payloads. |
| Approval action -> proposal status | Teacher approval changes proposal state but not lesson/classroom/student output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | I | `buildSafeRetrievalFilter` | mitigate | Require school/course/visibility/resource/grade/subject filters and `ragEligible: true` by default. |
| T-06-03-02 | E | Agent proposal approval | mitigate | DAL requires `assertActiveTeacher()` and stores approval state only; no direct lesson/classroom mutations. |
| T-06-03-03 | R | Agent outputs | mitigate | `createAgentProposal` and approvals write audit rows with actor/context/target metadata. |
| T-06-03-04 | T | Agent capability registry | mitigate | Registry is system-owned TypeScript data, not user-supplied executable code. |
</threat_model>
