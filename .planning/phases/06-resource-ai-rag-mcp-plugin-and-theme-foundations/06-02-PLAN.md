## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Teacher browser -> Server Action | Untrusted resource metadata enters server validation. |
| Server Action -> DAL | Validated input crosses into authorization and persistence. |
| DAL -> UI DTO | Scoped DB rows become sanitized resource card DTOs. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-02-01 | S | `createResourceAction` | mitigate | DAL calls `assertActiveTeacher()` and verifies school/course scope before persistence. |
| T-06-02-02 | T | Resource metadata input | mitigate | Server Actions validate with `CreateResourceInputSchema`/`UpdateResourceInputSchema`; DAL parses DTO output. |
| T-06-02-03 | I | Cross-school resources | mitigate | DAL filters by teacher school IDs and returns generic not-found/auth errors. |
| T-06-02-04 | R | Resource changes | accept | Full audit logs are not required for resource metadata; ownership/timestamps in resource rows provide minimal accountability. |
