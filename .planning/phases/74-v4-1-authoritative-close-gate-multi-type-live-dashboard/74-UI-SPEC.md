# Phase 74 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Phase scope:** Phase 74 不新增产品 UI，只把 Phase 73 已落地的两块真实表面冻结为 authoritative close-gate 观察契约：`/classroom` 内的「作答实时」tab 与 ended-session 的多题型 recap surface。

---

## Scope Locks

- 不新增 route；实时面板继续是 `/classroom` 控制室内的 sibling tab。
- 不新增写侧行为；dashboard 继续保持 teacher-only、read-only、zero-write posture。
- 不新增第二视觉语言；继续沿用 `DESIGN.md` 与 Phase 73 已锁定的 Lexend / tonal surface / no-line / gradient CTA 体系。
- Manual Surface Sign-Off 只观察现有真实产品表面，不允许用调试页、验证页或临时 mock surface 代替。

## Manual Sign-Off Observation Contract

| Surface | Entry | Must show | Must not show |
|--------|-------|-----------|---------------|
| `/classroom` 实时作答 tab | `/classroom?sessionId={id}&tab=live-answer`，教师身份进入 | 活跃 tab tonal 高亮、连接状态 badge、按题分布 / 作答流水双视图、`5/20/50` recent limit、无 1px divider | `grade*` / `update*` / `delete*` 类写操作入口、批改按钮、踢人按钮、第二数据真相源提示 |
| ended-session 多题型 recap | `/classroom?sessionId={id}` 且 session 已结束 | `题目复盘` section、5 题型 badge/统计块、作答/未作答人数、空态文案、tonal card layering | 独立 BI 页面感、排行/评分/竞争机制、深色硬边表格线、额外新 CTA 流程 |

**Observer checklist:**
1. 两个 surface 都必须运行在真实产品路径上。
2. 字体必须仍是 Lexend 体系，中文回退自然，无默认系统 UI 感。
3. 所有区块分隔继续靠留白、圆角、tonal shift，不允许出现 1px 实线分隔。
4. Accent 只用于 active state / live signal / 分布强调，不扩散成“全界面都蓝”。

## Interaction Contract

- `作答实时` 与 `课堂控制` 继续作为同级 tab；active tab 只用 tonal background shift + accent text 表示，不加硬边框。
- `作答实时` 内部继续保留 `按题分布` / `作答流水` 双视图；切换后内容区直接切换，不开 modal、不跳新页。
- 连接状态只通过 badge / inline status 呈现：`connected`、`reconnecting`、`fallback`、`closed`；错误不升级成打断式弹窗。
- 课堂结束后，实时面板必须退回“课堂已结束 → 跳转 recap”收口卡片；课后 recap 成为 authoritative read surface。
- 多题型 recap 继续按 `questionType` 分组渲染；不同题型允许不同统计组件，但卡片圆角、阴影、表面层级必须一致。

**Source:** `74-CONTEXT.md` D-10, `73-UI-SPEC.md`, `live-answer-dashboard-surface.tsx`, `classroom-session-recap-surface.tsx`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 无新增 CTA；沿用现有主入口 `作答实时` |
| Empty state heading | 暂无作答数据 |
| Empty state body | 当前课堂还没有收到任何学生作答。一旦学生开始提交，作答流水和选项分布会在这里实时刷新。 |
| Error state | 实时连接已断开。系统正在尝试重连；重连成功后作答流会自动恢复。已提交答案不会丢失。 |
| Destructive confirmation | 无新增 destructive action：Phase 74 不扩展任何破坏性操作，仍沿用既有 `结束课堂` 流程且不改其确认文案。 |

**Rule:** close-gate 文档与人工签核一律引用真实 UI 文案，不允许为了验证方便改写 surface copy。

**Source:** `73-UI-SPEC.md`, `live-answer-dashboard-surface.tsx`, `classroom-session-recap-surface.tsx`, `74-CONTEXT.md` D-05/D-10。
