## Trust boundaries

| Boundary | Description |
|----------|-------------|
| preview DTO -> UI | Incorrect shaping can misrepresent what teachers are about to launch. |
| published lesson data -> preview summary | Preview must not leak draft-only or invalid payload state. |
| launch page selection -> preview render | The selected lesson drives preview state and must stay consistent with launchable options. |

## STRIDE threat register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-01 | T | preview data shaping | mitigate | Derive summaries and cues from existing validated payload fields and launchable lesson records only. |
| T-12-02-02 | I | preview UI | mitigate | Render DTO-safe summaries and material labels only; do not expose raw payload JSON. |
| T-12-02-03 | D | launch route | mitigate | Keep preview inline and lightweight; do not introduce a separate route or modal workflow that adds navigation churn. |
| T-12-02-04 | R | duration cues | mitigate | Use explicit existing defaults (12/15/8) or exact stored values so preview timing is explainable and repeatable. |
</threat_model>
