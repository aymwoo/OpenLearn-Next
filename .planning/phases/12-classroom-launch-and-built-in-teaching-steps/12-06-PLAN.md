<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| seed manifest -> plugin registry | Wrong built-in manifest actions can make seeded system plugins unusable or inconsistent with the allowlist. |
| enabled plugin record -> built-in template resolution | Hard-coded fallbacks can bypass admin toggles and return templates for disabled system plugins. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-06-01 | T | `scripts/bootstrap-dev-db.ts` | mitigate | Seed only the explicit built-in actions already allowed by `registry.ts`. |
| T-12-06-02 | E | `listBuiltInTeachingStepTemplates()` | mitigate | Return templates only from enabled built-in plugin records that declare `insertBuiltInTeachingStepTemplate`. |
| T-12-06-03 | R | built-in registry truth | mitigate | Keep seed data and template resolution bound to the same typed action vocabulary. |
</threat_model>
