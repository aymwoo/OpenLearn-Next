| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-79-01 | Spoofing | governance-gate.ts | mitigate | assertActionExecutable 通过 deriveActiveSchoolScope 从认证 session 派生 actorId 和 schoolId，actorId 与 input.actorId 校验一致性，拒绝身份冒充 |
