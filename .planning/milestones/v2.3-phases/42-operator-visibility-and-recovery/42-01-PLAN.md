<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker process → heartbeat truth | 跨进程在线状态需要 durable heartbeat，不能依赖 web 内存或日志 |
| worker heartbeat writes → future overview DAL | 后台进程写 heartbeat 后，web 端必须通过 request-fresh 读取而不是假定 tag invalidation 一定到达 |
| registry metadata → future operator DAL | 后续 operator 查询必须以 registry visibility 为真相源，而不是 UI/DAL 自行越权开放 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | S | future `getAsyncTaskOperatorOverviewDTO` / `getAsyncTaskOperatorDetailDTO` | mitigate | 42-02 必须复用 membership scope resolver，仅允许 `developer/admin`，teacher 不允许 fallback。 |
| T-42-02 | I | registry visibility baseline | mitigate | `course_import.apply_batch` 在 registry 中改为 `school_operator`，后续 surface/DAL 不用绕过 truth source。 |
| T-42-03 | T | platform health computation | mitigate | worker connectivity 只取 `asyncWorkerHeartbeat` + BullMQ health snapshot，不取 web 进程 singleton。 |
| T-42-04 | D | heartbeat freshness | mitigate | 明确规定 42-02 的 operator health/detail DAL 为 request-fresh，不使用 `use cache` / cache tags 追 background writes。 |
| T-42-05 | E | operator scope drift | mitigate | 本计划只固定 foundation seam，不在 visibility 尚未稳定前让 UI 或 server action 各自推导 operator 权限。 |
</threat_model>
