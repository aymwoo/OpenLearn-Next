## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher course detail → lessons entry route | 未信任的 `courseId` route param 进入课程内课时读取 |
| lessons entry / editor query params → lesson DAL | 未信任的 `courseId` / `lessonId` 组合驱动 editor 加载 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-09 | E | `/teacher/courses/[courseId]/lessons` | mitigate | lessons entry 读取前校验 `courseId` 属于当前 teacher scope，拒绝跨 school 课程 |
| T-13-10 | T | `/teacher/editor` query params | mitigate | 根据显式 `courseId` / `lessonId` 只加载同课程资源，禁止回退到全局第一课时 |
| T-13-11 | I | 空态 handoff | mitigate | 无课时只暴露“新建第一个课时”动作，不泄露其他课程的 lesson metadata |
| T-13-12 | D | course-aware navigation consistency | mitigate | 课程详情、lessons entry、editor 三处统一使用 course-aware route contract，避免绕回全局入口造成错误上下文 |
</threat_model>
