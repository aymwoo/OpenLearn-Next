## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 行内图标与 badge 微间距（来源：`globals.css`） |
| sm | 8px | 紧凑标签、状态 chip、行内操作间距（来源：`globals.css`） |
| md | 16px | 默认表单项、摘要块、行内容间距（来源：`globals.css`） |
| lg | 24px | 审核卡片内边距、结果分组间距（来源：`globals.css` / `teacherSurfaceRhythm`） |
| xl | 32px | hero 内主要信息块间距、桌面双栏间距（来源：`globals.css`） |
| 2xl | 48px | 结果概览与行级结果的大区块切分（来源：`globals.css`） |

## Visual Hierarchy

首屏视觉焦点固定为“批次摘要 + 应用本批导入主 CTA”，让教师先判断这批数据是否可应用，而不是先掉进逐行细节。

信息层级顺序固定为：1）批次结果概览与主 CTA；2）命中已有课程 / failed / skipped 的分组摘要；3）逐行原因与状态细节；4）返回课程中心等次级动作。

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 应用本批导入 |
| Empty state heading | 还没有可审核的课程导入批次 |
| Empty state body | 先下载 CSV 模板并上传课程文件；系统会先逐行校验与匹配，再允许整批应用。 |
| Error state | 这批课程未能全部应用。请查看失败或跳过原因，修正 CSV 后重新导入，或返回课程中心继续处理。 |
| Destructive confirmation | 无破坏性动作（来源：`15-CONTEXT.md`）；整批应用使用非删除型确认文案：确认按当前逐行选择应用本批导入？ |
