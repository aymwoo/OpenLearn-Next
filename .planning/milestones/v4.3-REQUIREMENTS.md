# Requirements: OpenLearn Next

**Defined:** 2026-06-11
**Core Value:** 教师可以用可编程步骤编排一节课，并让学生端按进度可追踪地完成课堂流程。

## v4.3 Requirements

Requirements for v4.3 System Commands Bus（第一批）. Each maps to roadmap phases.

### System Commands

- [x] **SYS-01**: 插件可通过 `system.http.request` 经白名单域名+方法代理 HTTP 调用
  - 域名白名单支持通配符匹配（`*.example.com`）
  - 方法白名单（GET/POST/PUT/DELETE/PATCH）
  - SSRF 防护：DNS pinning（undici Agent `connect.lookup`）+ IPv6/IPv4-mapped/十进制编码检测 + redirect 链重校验
  - HTTPS-only（禁止 plain HTTP）
  - 默认超时 30s，响应大小上限 5MB
  - 请求/响应 header 白名单
  - 结构化拒因码：`domain_not_allowed` / `method_not_allowed` / `private_ip_blocked` / `redirect_denied`

- [x] **SYS-02**: 插件可通过 `system.config.get/set` 读写自身 KV 配置
  - 键名：`{schoolId}:{pluginId}:{key}` 三重前缀隔离，facade 注入
  - 禁止 key 包含 `:` 字符（Zod 层拒绝）
  - 禁止通配符/list 枚举接口
  - 值类型：JSON 可序列化值，单值上限 64KB
  - `get` 纯读走 DAL（不声明为 PlatformCommandType）
  - `set` 写经 Command Bus producer → `pluginOwnedBusinessData` upsert

### Manifest & Governance

- [x] **SYS-03**: `PluginManifest` 支持 `systemCommands` 声明段
  - Zod schema：`systemCommands` 为 `.optional()` 的 discriminated union
  - `system.http.request` 声明：`allowedDomains` (string[]) + `allowedMethods` (enum[]) + `maxResponseSize` + `defaultTimeout`
  - `system.config` 声明：`allowedKeys` (string[]，支持前缀通配 `homework:*`) + `maxValueSize`
  - Install preflight 校验声明合法性
  - 已有 quiz/homework manifest 全量兼容性扫描（`.optional()` 不破既有）

- [x] **SYS-04**: `dispatchSystemCommand` facade 作为统一入口
  - 三段式结构：治理门 → 判别派发 → 结果返回
  - 治理门前置：复用 `assertActionExecutable`（lifecycle + kill-switch + school scope）
  - 运行时 manifest 白名单 re-parse（每次调用从 `pluginRegistrations.manifestJson` 重新解析）
  - 统一 deny 审计写入器：每个拒绝点先写 audit 再抛错
  - schoolId 由认证 session 派生注入，绝不从 payload 读取

### Registry & Audit

- [x] **SYS-05**: Command Bus 注册与审计覆盖
  - `platformCommandRegistry` 新增 2 个 commandType：`system.http.request` + `system.config.set`
  - `PlatformCommandTypeSchema` 新增 `SystemCommandTypes` 数组
  - `PlatformCommandSchema` discriminated union 追加 2 个变体
  - governance audit 全量覆盖，新增 4 个 reasonCode：`domain_not_allowed` / `method_not_allowed` / `private_ip_blocked` / `config_key_denied`
  - 每次 system command 调用至少 1 条 audit 记录（deny 也记录）

## Out of Scope

| Feature | Reason |
|---------|--------|
| `system.http.request` 的 `*` 通配域名 | 安全风险，教育场景含学生 PII 数据 |
| 内网 IP 访问（含 localhost） | SSRF 防护核心红线 |
| HTTP (非 HTTPS) 请求 | 数据完整性 + 合规要求 |
| 响应体 streaming | v4.3 安全复杂度过高，延后评估 |
| `system.config` 的通配符枚举（list keys） | 信息泄露风险，插件不应能枚举所有 key |
| 跨插件 config 访问 | 数据隔离红线 |
| 其他 system command 类别（A/B/C/D/F/H/I） | v4.3 只做 E+G，其余延后 |
| 插件间数据共享 | 架构红线，不在此 milestone 范围内 |
