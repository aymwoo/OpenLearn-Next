## ROADMAP

**Milestone:** v3.1 Single-School Pilot Production Readiness (Plugin-First)

**Status:** ✅ SHIPPED

**Total plans:** 34

## Overview

`v3.1` 把仓库从“已有 classroom/plugin/platform baseline”推进到“单校试点可上线、可值守、可恢复”的正式样板交付。唯一真实样板固定为课堂投票插件，主链路固定为“教师设计 -> 发布 -> 开课 -> 学生课堂完成 -> 教师与 operator 验证”，容量口径固定为单课堂 40 名学生、同时 5 个课堂。

成功线不是继续扩平台抽象，而是在既有 SQLite + DAL truth、WebSocket-first classroom transport、optional Redis fanout、BullMQ worker、plugin governance 与 command/event baseline 之上，把 authoring、publish、runtime、operator recovery、deploy/release、backup/restore、load/degrade rehearsal 收口为单一 pilot close posture。

## Milestone Summary

**Decimal Phases:**

- Phase 60.1: 用 live rehearsal evidence 替换 dry-run close artifacts，并修复 repo-local SQLite contention blocker。
- Phase 60.2: 把 frozen voting contract 接入 runtime truth，关闭 `PLUG-01` / `CHAIN-03`。

**Key Decisions:**

- `v3.1` scope 固定为 single-school pilot production readiness，真实样板固定为 classroom voting plugin。
- SQLite + DAL 持续作为唯一 durable truth；Redis、WebSocket、BullMQ 只承担 delivery 或 orchestration 角色。
- release / close evidence 只有在 canonical deploy / rollback path 与 live rehearsal evidence 都成立时才算通过。
- transport fallback 继续保持 manual-only operator evidence，不升格为自动化 pass bit。

**Issues Resolved:**

- authoring -> publish -> runtime -> teacher / operator recovery -> deploy / restore / rehearsal 全链路闭环现在已落地为单一试点样板。
- 关闭了 `PLUG-01`、`CHAIN-03`、`PILOT-03`、`LOAD-01`、`LOAD-02` 的 close-gap blocker。
- 修复了 repo-local SQLite contention 与 incident-surface async cleanup 对 Phase 60 local verifier 的阻断。

**Issues Deferred:**

- 多校多租户 SaaS、通用 plugin marketplace、Agent / Skill runtime 扩张继续维持在本 milestone 外。
- `v2.4 Plugin Data Architecture & Default Plugins` 继续保留为冻结历史上下文，不自动恢复为 active scope。

**Technical Debt Incurred:**

- transport fallback closeout 仍需 manual evidence by design；后续如要自动化，必须在新 milestone 显式立项，而不是在 `v3.1` archive 中偷扩范围。
