<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| producer → command bus | untrusted payload/dedupe metadata crosses into authoritative mutation pipeline |
| command bus → SQLite ledger | partial-write or duplicate-write bugs can corrupt auditability |
| command ledger → plugin audits | attribution link can be lost if commandId is not persisted consistently |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-01 | T | `dispatchPlatformCommand` dedupe path | mitigate | Persist unique `dedupeKey` on `platformCommands` and resolve duplicates before execute per D-07/D-09. |
| T-51-02 | R | `platformCommands` / `platformCommandAttempts` | mitigate | Store stable command row + append-only attempt rows so retry history remains attributable per D-04/D-06. |
| T-51-03 | S/E | envelope actor metadata | mitigate | Keep actor/scope schemas explicit and make authorize stage mandatory before any handler executes. |
| T-51-04 | I | bus invalidation output | accept | Return tag names only; do not embed sensitive session/cache APIs in core logic. |
</threat_model>
