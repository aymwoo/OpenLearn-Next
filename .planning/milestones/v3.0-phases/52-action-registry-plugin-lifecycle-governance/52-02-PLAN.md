## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DAL truth → governance projection | durable lifecycle truth 被映射到对外 contract，必须防止语义漂移 |
| dependency graph → action visibility | 依赖/失败判断将直接影响动作可见性与恢复动作 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-02-01 | T | lifecycle projection mapping | mitigate | 使用显式 external lifecycle mapping，禁止 UI/adapter 直接消费 internal `mounted` / `ready` / `failed` 作为对外状态。 |
| T-52-02-02 | D | dependency failure handling | mitigate | dependency graph 仅阻断受影响链路，避免无关插件被连带停机。 |
| T-52-02-03 | I | operator diagnostics | mitigate | 只输出 stable reason code、substate、recommended recovery action，不暴露完整内部堆栈。 |
| T-52-02-04 | E | recovery flow | mitigate | projection 不触发 auto-recovery，恢复必须重新走显式 command surface。 |
</threat_model>
