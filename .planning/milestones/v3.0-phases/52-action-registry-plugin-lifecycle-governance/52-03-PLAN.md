<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| governance projection → host/server adapters | 统一治理 contract 被多个入口消费，必须避免入口各自放宽权限或泄露 blocked diagnostics |
| operator UI → uninstall commands | destructive governance flow 从预检进入真正卸载，必须防止 cleanup 被误触发 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-03-01 | I | executable catalog read API | mitigate | 普通 catalog 只返回 executable rows；blocked diagnostics 需要单独 operator/governance 入口。 |
| T-52-03-02 | E | host/server governance adapters | mitigate | adapters 统一消费 external lifecycle / reason code contract，不允许绕过 registry gating 直接判定 runnable。 |
| T-52-03-03 | T | uninstall cleanup flow | mitigate | cleanup 仅在 preflight 分类与显式确认后触发，retain 保持默认分支。 |
| T-52-03-04 | D | operator recovery UX | mitigate | UI 只提供显式 `enable` / `retry` / `resume` / `reconcile` 恢复动作，不暗示自动恢复。 |
</threat_model>
