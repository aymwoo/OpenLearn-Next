<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 插件声明 → 编译器 | 声明式 dataModel 是受信前输入，编译期二次过 `PluginDataModelSchema`，编译器只 writeFileSync 不执行 SQL |
| 插件/前端入参 → allowlist 校验 | 不受信运行时输入跨界；表/列/索引/groupBy/payload 全部对照服务端常量 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-68-01 | Tampering(Injection) | allowlist.validate* | mitigate | 表/列名只能来自生成 const；原始 SQL/DDL 关键字与自由 where 直接拒（raw_sql_rejected/free_where_rejected）— ASVS L1 V5 输入校验 |
| T-68-02 | Information Disclosure | groupBy/index 列 | mitigate | getByIndex/groupBy 仅命中声明 indexes 列，越界 → unindexed/unknown_column_rejected（D-07）|
| T-68-03 | Elevation(Cross-tenant) | payload schoolId | mitigate | payload 含 schoolId 即 cross_school_rejected；schoolId 仅由 session 推导（SC2）|
| T-68-04 | Tampering(Drift) | 生成白名单 | mitigate | 编译期确定性派生 + `git diff --exit-code` 零漂移闸门（D-06）— 阻断手写并行常量 |
</threat_model>
