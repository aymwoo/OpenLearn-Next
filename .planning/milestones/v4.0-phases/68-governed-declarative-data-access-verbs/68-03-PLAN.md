| Boundary | Description |
|----------|-------------|
| producer/handler 入参 → Command Bus | 不受信 payload 跨界；authorize 在写库前过治理门 + 白名单 |
| Command Bus → SQLite | 唯一 durable 写入边界；命令记录 + 自有表是单一权威 |

| T-68-09 | Tampering(2nd truth) | 写入权威源 | mitigate | 写入仅 Command Bus → DAL → SQLite；emittedEvents/WS/Redis 只投递不落库权威（SC3 / Pitfall #8）|
| T-68-10 | Elevation(Cross-tenant) | handler.authorize | mitigate | payload schoolId → cross_school_rejected；actor/schoolId 取鉴权闭包，非 payload — ASVS L1 V1 |
