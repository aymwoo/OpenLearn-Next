<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upgrade preflight -> upgrade execute | preflight 输出的 blocker/parity 直接决定是否允许 destructive migration |
| uninstall preflight -> cleanup execute | confirmation token 与 impact counts 必须在同一后端真相源复核 |
| live classroom occupancy query -> operator action | blocker 如果只在 UI 生效会造成真实数据破坏 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-03-1 | T | semver upgrade execute | mitigate | execute 只能复用 `backfill -> verify -> cutover`，verify 失败不切版本并保留旧版本继续可用 |
| T-71-03-2 | T/R | cleanup token + audit | mitigate | cleanup token 基于真实 quiz rows 与 ended sessions 计数生成，token mismatch 记 `denied` audit，成功后才记 `allowed` |
| T-71-03-3 | D | active classroom blockers | mitigate | upgrade/uninstall 的 preflight 与 execute 都查询 live sessions 并硬拒绝，返回 affected classroom/session 清单而非前端猜测 |
</threat_model>
