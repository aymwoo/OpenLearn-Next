<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external catalog → install preflight | 外部 manifest/dataModel 进入治理边界，必须先校验再写 registration |
| retained recovery tx → plugin-owned rows | recovery 会批量改写 plugin-owned 数据的 pluginId，必须避免 identity drift 或 silent reuse |
| server actions → governed command chain | install/recover 必须继续经过 command handler，而不是在 action 层直接落库 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-02-1 | S/T | external install preflight | mitigate | 用 `PluginManifestSchema` + dataModel 校验 + `(schoolId, pluginKey)` / `(schoolId, dbNamespace)` 唯一检查，在写 registration 前拒绝冲突和伪造 manifest |
| T-71-02-2 | T | retained recovery handoff | mitigate | recovery 只能走显式 recover-install path，并在单事务里新建 registration + 批量改写 child rows 的 `pluginId`，禁止 silent reuse 旧 id |
| T-71-02-3 | R | named reject reasons | mitigate | action 返回 DAL/治理层原始 reason token；测试断言 token 不被 generic fallback 覆盖，保证 UI 与审计可追踪 |
</threat_model>
