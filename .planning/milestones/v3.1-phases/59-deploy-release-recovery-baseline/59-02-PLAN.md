<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous HTTP caller → ops probe routes | 未认证请求会读取系统 posture，必须限制信息粒度。 |
| DAL/manifest data → HTTP JSON | 内部状态被转换成对外 probe payload，容易泄漏实现细节。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-03 | Information Disclosure | `/api/ready`, `/api/release` | mitigate | 只返回 posture、reason、nextStep、release metadata；不输出 DSN、secret、stack trace、raw environment。 |
| T-59-04 | Denial of Service | `getReadyPayload()` | mitigate | route 只聚合已有 DAL snapshots 与 manifest file read，不引入无限重试或阻塞式外部探测；失败返回 explicit 503。 |
</threat_model>
