<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| student runtime payload → runtime-submit | student 传来的 answer/state 不能直接决定是否接受提交 |
| runtime-submit → canonical attempts/progress | 只有 round open 且非重复 payload 才能进入 SQLite durable truth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-04 | T | `submitRuntimeState()` | mitigate | server-side 依据 current round artifact、published snapshot、actor scope 重建 context，不信任 client 自报 round state。 |
| T-57-05 | R | duplicate submit handling | mitigate | 用 same-round same-payload dedupe 直接返回现有 latest truth，避免重复 attempt 破坏 canonical 审计。 |
| T-57-06 | I | reconnect recovery | mitigate | `getStudentPlayerPersonalDTO()` 始终从 latest runtime state + latest attempt + round status 恢复，不从 local-only state 恢复。 |
</threat_model>
