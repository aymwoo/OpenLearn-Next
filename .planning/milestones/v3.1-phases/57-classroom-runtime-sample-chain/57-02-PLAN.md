<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher browser control → runtime teacher control action | teacher 发起的 round command 必须在服务端重验 session/version/teacher ownership |
| runtime teacher control → durable round truth | round open/closed 不能只存在 socket 内存态，必须落 SQLite truth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-02 | T | `recordRuntimeTeacherControl` | mitigate | 继续使用 `expectedVersion` / `VERSION_CONFLICT` 返回最新 snapshot，防止旧面板覆盖新课堂状态。 |
| T-57-03 | R | voting round command trail | mitigate | 每次开始/结束都写 `classroomEvidence` system artifact，带 step/version/teacher identity，形成 durable 审计链。 |
| T-57-04 | D | post-launch degraded posture | mitigate | degraded 只走 in-class warning copy，不触发自动 `endClassroomSessionAction()`，避免错误中断 live session。 |
</threat_model>
