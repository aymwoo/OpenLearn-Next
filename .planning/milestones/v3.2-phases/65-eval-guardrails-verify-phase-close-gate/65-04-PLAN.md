<objective>
Register the `lesson.draft.rejected` event contract and make the command handler record guardrail rejections as a recoverable rejected outcome distinct from real failures (EVAL-02 "被拦截输出记录可查", D-11/D-07).

Purpose: SC2 requires intercepted output to be recorded and queryable. A guardrail rejection is NOT a system failure — it is an expected business outcome that must produce a queryable domain event with a summary-only payload, while genuine generation errors keep the existing single generic-failure semantics (D-53-08). The handler distinguishes the two via `instanceof DraftGuardrailRejection`.
Output: contract registration in `events/contracts.ts` (+ test) and the handler branch in `commands/handlers/lesson-draft.ts` (+ test).
</objective>
