<objective>
Create the teacher-facing server action that triggers LessonAgent drafting, gated by the
`lesson_agent_enabled` feature flag at the authorize boundary (locked decision D-03). The flag is
read via `getAgentRegistryDTO` (the registry is the source of truth); when OFF the action returns
`AGENT_DISABLED` and dispatches NOTHING (defense in depth — UI also hides the trigger, but backend

`draftLessonStep` (which now runs the run→persist closure from Plan 02).
