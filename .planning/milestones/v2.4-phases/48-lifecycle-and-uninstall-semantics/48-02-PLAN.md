<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Settings Labs form/dialog → Server Actions | 未受信任 UI 输入触发生命周期切换、kill switch 与卸载动作，必须继续由 action + DAL 复核 school scope 与 actor 身份。 |
| preflight summary → uninstall confirm | operator 依据 preflight 决定是否执行 destructive action，preflight 与 uninstall 若规则不一致会造成误导性删除。 |
| lifecycle transition → theme side effect | 生命周期切换与 theme registry 写入跨越两个持久化面，若顺序错误会留下“失败请求却有副作用”的脏状态。 |
