<objective>
把当前 classroom realtime transport 推进到可执行的 WebSocket cutover 起点：先锁定
`ws` 握手、双向消息信封、连接注册表和 route 边界，确保后续 teacher control、student
sync 与 runtime command 可以在同一 channel contract 上演进。

Purpose: 如果握手、消息格式和连接持有关系没有先变成单一 truth，后续把 SSE consumer、
teacher command 和 runtime interaction 一起迁移时会出现并行协议、无约束 payload 或
scope 漂移。
Output: authenticated Node websocket upgrade host, HTTP 426 route boundary, typed envelope,
session-scoped connection registry, focused tests.
</objective>
