<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Node ws upgrade | 未认证客户端可伪造 actor、sessionId、cookies、query actor scope |
| ws server → DAL snapshot read | raw upgrade 不具备 App Router request context，容易绕过既有 auth helper |
| gateway → websocket adapter | transport metadata 漂移会把错误 actor/kind 广播给 consumer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-02-01 | S | `ws-auth.ts` | mitigate | 仅从 Auth.js token + active memberships + `classMembers.userId/role` + `session.teacherId` 推导 actor scope，拒绝信任 query actor 身份 |
| T-36-02-02 | E | `ws-server.ts` | mitigate | `sendSnapshot()` 只调用 `getClassroomSnapshotForActor()`，禁止 raw upgrade 直接复用 `getCurrentUserDTO()` 路径 |
| T-36-02-03 | T | `ws-server.ts` / `classroom.ts` | mitigate | `teacher.control` 只走 actor-aware canonical mutation helper；`runtime.command` 只走 `recordTeacherControlEvent()`，不在 ws server 直接写 classroom/runtime 表 |
| T-36-02-04 | T | `ws-adapter.ts` / `gateway.ts` | mitigate | canonical `kind/correlationId/truthRef` 原样透传；supplemental websocket failure 单独 trace，避免静默篡改 transport observability |
</threat_model>
