<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| websocket consumer → UI state | 若 consumer 直接信任 websocket payload，会把 transport 临时态误当业务真相 |
| player shell → runtime iframe bridge | 若 runtime event 绕过 `RuntimeHostClient`，会破坏现有 typed bridge 安全边界 |
| rollback path → classroom/player UX | 若 websocket 失败后没有保持 SSE/manual reconnect，课堂会丢失恢复语义 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-03-01 | T | `classroom-live-snapshot-refresh.tsx` | mitigate | 只在 `kind === "classroom.snapshot"` 时刷新，fallback 到 `/api/classroom/[sessionId]/events` |
| T-36-03-02 | T | `classroom-runtime-client.tsx` | mitigate | websocket payload 先 fetch durable snapshot 再校正 UI，presence 继续通过 `touchClassroomPresenceAction` |
| T-36-03-03 | I | `runtime-host-client.tsx` | mitigate | 所有 runtime event 继续走 `createRuntimeSnapshotUpdateMessage()` typed bridge，不直接把 websocket payload 注入 iframe |
</threat_model>
