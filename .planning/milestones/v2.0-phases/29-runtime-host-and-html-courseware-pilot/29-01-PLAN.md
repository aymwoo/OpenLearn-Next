<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| iframe runtime -> browser host | runtime 发出的浏览器消息是不可信输入，必须重新验证类型与实例身份 |
| browser host -> server boundary | 浏览器宿主不能绕开现有 runtime host actions 直接写 truth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-29-01-01 | S | browser bridge | mitigate | runtime message 必须按 typed kind + runtime instance id 校验，拒绝宽松裸 payload |
| T-29-01-02 | E | iframe sandbox | mitigate | iframe 只通过 sandboxed host shell 运行，不暴露 DAL、DB、cookies、SSE 直连 |
| T-29-01-03 | T | host size/layout | mitigate | height sync 只允许 iframe 报告高度，实际应用由 host 决定并节流 |

</threat_model>
