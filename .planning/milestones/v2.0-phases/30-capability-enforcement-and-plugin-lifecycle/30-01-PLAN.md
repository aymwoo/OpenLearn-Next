focused governance tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| client runtime/plugin request -> server host gateway | 客户端请求不可信，最终 capability 与 permission 决策必须由服务端重算 |
| runtime/plugin descriptor -> allowed host action | descriptor/manifest 只能声明请求，不等于最终授权 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-30-01-01 | E | host action dispatch | mitigate | 继续使用 `createGuardedHostAction`，不新增可绕过的第二入口 |
| T-30-01-02 | S | capability source | mitigate | 只信任 snapshot/registration truth，不信任 iframe 或 client payload 自报 capability |
| T-30-01-03 | R | denied result semantics | mitigate | 用 typed reason code 固定 refusal language，避免 silent failure |

</threat_model>
