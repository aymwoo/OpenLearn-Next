<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| latest lifecycle state -> host dispatch | 若状态只靠临时推断，blocked package/runtime 仍可能继续执行 |
| lifecycle transition history -> operator truth | 若缺少 transition log，后续 inspector 无法解释为何进入 failed 或 suspended |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-30-03-01 | T | lifecycle latest state | mitigate | 建立 current state 持久 truth，不再只依赖 `enabled` 布尔值 |
| T-30-03-02 | R | transition history | mitigate | append-only transition log 保留状态变迁与时间序列 |
| T-30-03-03 | E | blocked package/runtime | mitigate | `disabled`、`suspended`、`failed`、kill switch 全部成为硬阻断条件 |

</threat_model>
