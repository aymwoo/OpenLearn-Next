<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| host result envelope -> iframe UI | 如果 envelope 不受控，runtime 可能错误进入 success/terminal state |
| player shell -> runtime failure UX | 如果失败处理跳出当前 surface，会丢失用户输入并破坏课堂上下文 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-32-02-01 | T | terminal submit state | mitigate | 只在 trusted submit result `ok` 时进入 terminal locked state，失败时不锁定也不丢草稿 |
| T-32-02-02 | D | player failure recovery | mitigate | 失败后停留当前 runtime surface 并提供 retry CTA，避免 route bounce 造成不可恢复中断 |
| T-32-02-03 | I | success summary payload | mitigate | 仅展示 UI-ready summary，不把 raw runtime state 或 internal bridge metadata 暴露给学生 |

</threat_model>
