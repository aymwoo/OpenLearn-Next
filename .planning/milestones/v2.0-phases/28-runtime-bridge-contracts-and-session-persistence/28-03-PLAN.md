<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runtime-originated request → host-side action | runtime 发出的请求是不可信输入，必须重新做 actor/school/permission 校验 |
| runtime submit → classroom/learning truth | 若 save/submit 混淆，会制造虚假正式提交或覆盖现有真相源 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-03-01 | S | runtime host request actor scope | mitigate | 所有 bootstrap/save/submit/event 请求继续通过 `createGuardedHostAction` 解析 trusted actor 与 school scope |
| T-28-03-02 | T | save/submit semantic drift | mitigate | `saveRuntimeState` 只写 runtime state/outbox；`submitRuntimeState` 才桥接 `classroomEvidence` 与 task/quiz truth |
| T-28-03-03 | E | runtime DB bypass | mitigate | runtime server actions 只调用 host-side service / DAL，禁止 runtime path 直接 import `db` 或写原表 |
| T-28-03-04 | I | progress truth drift | mitigate | runtime submit 必须显式更新 `lessonStepProgress` 或等价 progress 派生链，再刷新 downstream `progress` tags，禁止 tag-only freshness |
</threat_model>
