<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher-authored payload → published snapshot | 未经约束的 runtime descriptor 进入 lesson truth，会影响后续 host/runtime 安全边界 |
| shared contracts → future runtime consumers | 若合同混入实现或 secrets，后续 iframe/runtime 边界会被污染 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-01-01 | T | lesson payload runtime block | mitigate | 使用 `RuntimeDescriptorSchema` 约束 `payload.runtime`，禁止自由 JSON 漂入 lesson snapshot |
| T-28-01-02 | I | bootstrap/result contract | mitigate | typed result envelope 只暴露 allowlisted result/error fields，不引入 cookies、raw rows、secrets |
| T-28-01-03 | E | contracts root | mitigate | 继续用 purity test 阻止 `server-only`、`db.`、`updateTag(`、`"use server"` 进入 contracts 文件 |
</threat_model>
