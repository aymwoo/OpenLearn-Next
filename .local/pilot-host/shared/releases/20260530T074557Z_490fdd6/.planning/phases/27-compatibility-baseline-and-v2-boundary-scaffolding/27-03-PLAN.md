<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host-side feature facade → contracts root | host/runtime 共享协议若混入实现，会扩大 blast radius |
| contracts root → future runtime/plugin consumers | 任何非纯 contract 内容都会把 secrets、side effects 或 DB concern 泄漏到未来 runtime boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03-01 | T | contracts root purity | mitigate | 用静态 focused tests 禁止 `db`、`updateTag`、`use server`、`server-only` 等实现令牌进入 contracts root |
| T-27-03-02 | I | bridge/event schemas | mitigate | 所有 host/runtime envelope 仅暴露最小 typed fields，不把 cookies、raw DB rows、secret config 放入 schema |
| T-27-03-03 | E | permission descriptors | mitigate | permissions 模块只定义 capability/actor scope contract，不直接执行授权或 side effects，执行留给 host guards |
</threat_model>
