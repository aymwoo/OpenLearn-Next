<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted event ledger → subscriber callbacks | delivery consumers see after-fact facts and must not become mutation authorities |
| platform adapter contracts → future Redis/WebSocket implementations | future transports must not claim replay/truth ownership |
| platform seam → runtime seam | import or conceptual bleed can collapse the runtime/platform separation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-09 | T/E | `events/bus.ts` subscriber execution | mitigate | Load only persisted rows from the ledger and keep callbacks side-effect consumers, not truth writers. |
| T-53-10 | T | future bridge contracts | mitigate | Declare adapter ownership as delivery-only and reject any adapter claiming canonical truth or replay authority. |
| T-53-11 | D | subscriber failure isolation | mitigate | Record dispatch result per subscriber/dispatch row and continue unrelated deliveries. |
| T-53-12 | T/I | runtime/platform seam | mitigate | Keep platform adapters in `src/features/platform-core/events/*` and forbid runtime transport imports except reference tests/shape notes. |
</threat_model>
