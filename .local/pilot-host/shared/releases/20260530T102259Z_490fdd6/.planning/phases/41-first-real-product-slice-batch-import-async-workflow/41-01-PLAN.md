<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher client → server action | 未受信任输入进入 batch apply 触发路径 |
| server action → enqueue/DAL | 需要防止越权 batch 访问与重复触发 |
| worker runtime → DAL execution helper | 重试或重复投递可能导致重复业务写入 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-01 | S | `applyCourseImportAction` / `prepareCourseImport...` | mitigate | 继续通过 `assertActiveTeacher()` + batch school scope 校验，只允许 owner teacher 触发指定 batch。 |
| T-41-02 | T | active task dedupe path | mitigate | 对 `course_import_batch` 做 active-status lookup，重复点击复用现有 task，避免并发创建两个 active tasks。 |
| T-41-03 | R | worker execution helper | mitigate | 每次 attempt 重新读取 durable rows 并写 append-only task events/result snapshot，保留 attempt history 与结果来源。 |
| T-41-04 | I | dispatch failure result | mitigate | dispatch 失败时返回明确 failed posture，不暴露其他 teacher batch/task 数据，只回当前 batch 范围信息。 |
| T-41-05 | D | duplicate delivery / retry | mitigate | worker 只基于 durable row truth 收敛写入，并把已成功/可跳过行识别为 skip，避免无限重写。 |
| T-41-06 | E | worker processor | mitigate | processor 只调用 server-side helper，不直接 import DB 或绕过 DAL authorization and write discipline。 |
</threat_model>
