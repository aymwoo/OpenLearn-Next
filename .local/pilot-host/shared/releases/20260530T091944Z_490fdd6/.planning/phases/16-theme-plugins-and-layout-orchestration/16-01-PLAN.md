<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin manifest → theme schema | Untrusted plugin JSON crosses into validated layout contract |
| theme schema → runtime compiler | Declared shell/region/module data becomes executable runtime layout metadata |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | T | `src/lib/dto/resource-ai.ts` | mitigate | Replace freeform layout records with explicit enums and allowlisted schemas so plugin manifests cannot smuggle arbitrary layout fields. |
| T-16-02 | E | `src/server/themes/tokens.ts` | mitigate | Compile only allowlisted regions, modules, and split enums; reject any class/style/script-like payload before runtime use. |
| T-16-03 | D | `src/server/themes/tokens.ts` | mitigate | Enforce region-level fallback for invalid overrides so a partial manifest error cannot break the entire teacher shell. |
| T-16-04 | I | `src/lib/theme-layout/route-surface-registry.ts` | mitigate | Restrict page overrides to a closed teacher-facing surface registry instead of raw pathname matching. |
</threat_model>
