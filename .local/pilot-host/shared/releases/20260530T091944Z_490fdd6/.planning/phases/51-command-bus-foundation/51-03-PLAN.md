<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server Action / host / bootstrap producer → shared producer seam | producer-specific shortcuts can reintroduce bypass paths |
| shared producer seam → bus | inconsistent envelope generation can fracture dedupe/attribution semantics |
| Server Action edge → cache invalidation | cache APIs must remain entrypoint-owned and not leak into bus core |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-09 | T/E | migrated producers bypassing bus | mitigate | Replace direct DAL mutation imports in `plugin-actions.ts`, `plugin-host.ts`, and `bootstrap-dev-db.ts` with the shared producer seam and enforce with `verify:phase51`. |
| T-51-10 | S | host actor dispatch | mitigate | Preserve `createGuardedHostAction` + resolved actor scope checks before issuing governance commands. |
| T-51-11 | R | cache invalidation ownership | mitigate | Keep `updateTag()` only in Server Actions and consume returned invalidation tags from producer output rather than calling cache APIs in core code. |
| T-51-12 | T | bootstrap install path duplicates | mitigate | Route bootstrap registration through explicit `plugin.install` producer so dedupe semantics match UI/host producers. |
</threat_model>
