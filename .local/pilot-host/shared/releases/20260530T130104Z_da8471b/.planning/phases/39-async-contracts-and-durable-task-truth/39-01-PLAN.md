## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer definition → registry helper | 新任务定义进入平台合同层，必须阻止缺少 visibility/entity metadata 的不完整定义 |
| product DTO → UI surfaces | UI 只能消费 DTO schema，不得读取未约束的 raw payload JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-01 | T | `src/features/async-tasks/server/registry.ts` | mitigate | 通过 typed helper 强制 `visibilityScope`、`entityRefKind`、metadata key 必填，拒绝篡改成不完整任务定义 |
| T-39-02 | I | `src/features/async-tasks/shared/dto.ts` | mitigate | DTO schema 只暴露结构化 progress/result summary，不直接泄露 raw payload truth |
| T-39-03 | E | `src/features/async-tasks/index.ts` | accept | public barrel 只做 re-export，无权限提升逻辑，风险低且可由 typecheck 覆盖 |
</threat_model>
