<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| seeded plugin manifest → theme registry | 开发 seed 写入的主题 token 仍属于不完全可信输入，必须经过 schema 与 allowlist 守卫 |
| theme CSS variables → shell layout | 主题变量会影响壳层布局，必须限制可覆盖的属性范围与值类型 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-quick-01 | T | `src/server/themes/tokens.ts` | mitigate | 仅允许白名单 layout key 与长度类值进入 `--layout-*` 输出，拒绝任意属性注入 |
| T-quick-02 | D | `src/components/shell/teacher-sidebar-shell.tsx` | mitigate | 所有 layout 变量都必须带当前布局 fallback，避免主题缺失或脏数据导致教师壳层塌陷 |
| T-quick-03 | I | `src/components/surfaces/settings-surface.tsx` | mitigate | 设置页继续只展示当前学校范围内的 valid theme，不新增跨学校读取或客户端直连数据路径 |
</threat_model>
