<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Teacher input -> client draft state | 教师在 modal 中输入内容会实时驱动预览，但不应直接触发服务端写入。 |
| Client draft state -> autosave Server Action | 只有显式保存动作才能把 draft payload 送入 `autosaveLessonStepAction`。 |
| Built-in provenance display -> payload persistence | 内置环节来源信息需要从 DTO 显示到保存 payload，不能在 UI 重构时丢失。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-260510-u37-01 | Tampering | `src/components/authoring/lesson-step-editor.tsx` | mitigate | 保持 `lessonStepPayloadSchema.safeParse` 与 `buildPayload` 主链路不变，实时预览只读 draft state，不绕过保存校验。 |
| T-260510-u37-02 | Spoofing | `src/components/authoring/lesson-authoring-workspace.tsx` | mitigate | modal 只绑定当前 `selectedStepId` 对应步骤，关闭/切换时重置打开状态，避免把错误步骤内容展示成当前编辑对象。 |
| T-260510-u37-03 | Information disclosure | `src/components/authoring/lesson-step-editor.tsx` | accept | 预览仅展示教师当前草稿字段与已有 builtInSource/materialRefs 摘要，不引入新的敏感数据源或学生 runtime 数据。 |
| T-260510-u37-04 | Denial of service | `src/components/authoring/lesson-authoring-workspace.test.tsx` | mitigate | 用 focused tests 固定 modal 打开/关闭和实时预览合同，防止后续回归导致 editor 常驻、重复挂载或无法关闭。 |
</threat_model>
