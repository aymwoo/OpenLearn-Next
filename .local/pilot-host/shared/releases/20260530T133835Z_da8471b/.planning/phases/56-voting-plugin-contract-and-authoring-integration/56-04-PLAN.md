<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Server Action | 教师表单输入进入服务端，属于不可信输入 |
| Server Action → DAL | 保存请求必须在单一权限边界内完成校验、冲突检查与缓存失效 |
| DAL → plugin extension truth | `plugin_ext_lesson_step` 是 durable truth，重复写入与跨校写入都必须受控 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-56-04-01 | T | `saveVotingLessonStepAction` input | mitigate | 用 Zod + `ClassroomVotingAuthoringConfigSchema` 校验 prompt/options/window，并拒绝非 classroomVoting step |
