<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| product setting → deploy capability | 前端 toggle 不能越权覆盖部署层禁用 Redis 的事实 |
| session create → transport publish | 会话快照必须稳定，后续 publish 不能偷偷回读全局当前值 |
| websocket adapter → Redis seam | Redis 只能做 delivery，不得反向变成 truth store |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01-01 | E | `system-transport-settings-actions.ts` | mitigate | 仅允许 `developer` / `super_admin` 修改全局设置，并在 DAL 重复校验 D-07 |
| T-37-01-02 | T | `launchClassroomSession()` | mitigate | 在事务内写 `transportModeSnapshot`，后续只读 session snapshot，禁止热切换 D-08/D-09 |
| T-37-01-03 | I | Redis topic layer | mitigate | topic 只含 session+channel，避免 school-wide 或 instance-wide 混流，落实 D-11~D-14 |
</threat_model>
