<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route params → operator DAL | 未受信任 `taskId` 与页面请求进入 operator 读取面，必须再次做 school scope 与 visibility 校验 |
| request-fresh DAL → UI surface | surface 不能自己拼接底层事件，也不能通过客户端缓存遮蔽后台 heartbeat / retry 变化 |
| overview link → detail route | 只能链接到 operator scope 可见任务，不能让 UI 下钻到越权 task |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-06 | I | `getAsyncTaskOperatorDetailDTO` | mitigate | 读取基础 detail 后再次按 schoolIds + visibility 校验，失败直接拒绝。 |
| T-42-07 | T | attempt grouping | mitigate | 在 DAL 中统一按 `attemptNumber` 聚合 started/terminal/recovery 事件，禁止 surface 自行从 history 猜。 |
| T-42-08 | R | latest error card | mitigate | latest error 仅来自 durable failure context 与 history，不从 transient client state 拼接。 |
| T-42-09 | D | operator health/detail freshness | mitigate | overview/detail DAL 故意不使用 Next data cache，避免后台 heartbeat/recovery 写入无法可靠失效导致陈旧页面。 |
| T-42-10 | E | overview → detail navigation | mitigate | 只输出当前 operator scope 内 problem task 链接，UI 不自行拼 school/task 查询。 |
</threat_model>
