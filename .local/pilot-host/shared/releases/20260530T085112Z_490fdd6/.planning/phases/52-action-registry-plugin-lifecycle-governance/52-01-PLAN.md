<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| static code catalog → projected descriptor | 代码受控实现被投影成 machine-readable catalog，必须防止 authority 漂移 |
| plugin manifest metadata → action descriptor | 非受控 manifest 字段进入 descriptor 时必须保持 schema 校验与静态执行边界 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-01-01 | T | `src/server/plugins/registry.ts` | mitigate | 保持 static implementation catalog posture，只允许 descriptor projection 读取，不允许恢复动态 authority。 |
| T-52-01-02 | I | action catalog DTO | mitigate | 将 executable catalog 与 blocked diagnostics 分离，默认 catalog 不暴露 blocked reason details。 |
| T-52-01-03 | E | descriptor metadata | mitigate | descriptor schema 显式限制 implementation source 为 main-repo static implementation，拒绝 remote code / manifest execution。 |
</threat_model>
