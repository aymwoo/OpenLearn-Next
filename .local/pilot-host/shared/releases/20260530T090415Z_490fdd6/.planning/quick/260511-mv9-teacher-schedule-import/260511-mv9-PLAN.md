<objective>
将 `/teacher/schedule/import` 的 CSV 导入模板表头从英文字段名改为中文字段名，同时让导入 action 能识别中文字段并映射回英文字段供 schema 校验。

Purpose: 提升教师填写体验，降低首次导入错误率。
Output: 中文列名模板、中文字段解析层与对应回归测试。
</objective>

<context>
@src/features/schedule/import/template.ts
@src/features/schedule/import/template.test.ts
@src/features/schedule/shared/dto/import.ts
@src/features/schedule/import/actions.ts

中文列名映射：
- 源记录标识 → sourceRowKey
- 学期名称 → termName
- 星期(0-6) → weekday
- 节次标签 → bellSlotLabel
- 班级名称 → className
- 课程名称 → courseTitle
- 教师姓名 → teacherName
- 教室标签 → roomLabel

约束：weekday 保持 0-6 数值语义；`ScheduleImportDraftRowInputSchema` 不改英文字段名；不扩散到 schedule 其它子域。
</context>
