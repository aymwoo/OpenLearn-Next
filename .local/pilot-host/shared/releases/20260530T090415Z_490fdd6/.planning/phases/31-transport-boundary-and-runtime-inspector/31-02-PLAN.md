<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| classroom/runtime durable write -> gateway publish | 若 publish 先于 truth write，会把 delivery attempt 误当成成功业务事件 |
| SSE route -> consumer trace | route 只能记录 trace，不能回写课堂状态或放宽授权 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-31-02-01 | T | runtime host publish path | mitigate | 移除 direct SSE call，要求 durable truth 成立后再 publishTransportEvent |
| T-31-02-02 | R | classroom event fanout | mitigate | classroom durable event 与 transport trace 通过 correlation/version 关联，供 inspector 追溯 |
| T-31-02-03 | E | SSE route | mitigate | SSE route 只做 authorized snapshot emit 与 trace update，不新增 truth write shortcut |

</threat_model>
