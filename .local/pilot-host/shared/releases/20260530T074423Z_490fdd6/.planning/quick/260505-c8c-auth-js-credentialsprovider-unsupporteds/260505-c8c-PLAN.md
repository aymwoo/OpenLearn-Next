<objective>
修复 Auth.js v5 CredentialsProvider 登录时报 `UnsupportedStrategy` 的问题。

Purpose: Auth.js 的 credentials 登录要求 `session.strategy = "jwt"`，不能使用 database session strategy；同时必须保持现有 edge-safe split，避免 proxy 路径加载 DB、Drizzle adapter、bcrypt 等 Node-only 依赖。

Output: 一个聚焦修复计划，执行后 credentials 登录使用 JWT session，并保留 DB-backed authorize 查询和 edge-safe proxy 配置。
</objective>
