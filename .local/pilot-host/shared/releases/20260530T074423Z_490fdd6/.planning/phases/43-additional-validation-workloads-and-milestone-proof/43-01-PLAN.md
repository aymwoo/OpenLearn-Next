<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher action → reminder server orchestration | 教师输入的 channel/recipientScope/offsetMinutes 会跨入服务端调度边界 |
| due-dispatch seam → async task creation | system-owned 到点触发会把 `scheduleReminderDispatch` 转成 async task，必须避免提前建 task 或重复建 task |
| async worker → reminder dispatch provider | worker 会把 payload 发送到通知分发边界，必须防止 secret/material 泄露 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-01 | T | `src/features/schedule/reminders/server.ts` planned dispatch path | mitigate | 继续用 Zod + teacher school scope 校验 rule 输入，只允许 `scheduleReminderDispatch` durable row 进入 due seam；`entityType/entityId` 固定为 dispatch 级 identity，防止篡改到 rule 级聚合 |
| T-43-02 | I | `src/server/schedule/reminder-dispatch.ts` payload handoff | mitigate | worker 只能调用现有 `dispatchScheduleReminder()`，保留 `assertNoSecretMaterial()` 与 channel allowlist，不允许 processor 直接写第三方通知代码 |
| T-43-05 | T | due-time task creation | mitigate | 到点前不创建 reminder delivery task；due seam 必须检查 dispatch identity，避免同一 dispatch 被重复 task 化 |
</threat_model>
