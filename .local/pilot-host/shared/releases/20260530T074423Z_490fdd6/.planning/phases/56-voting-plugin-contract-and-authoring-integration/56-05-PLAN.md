<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin registry truth → authoring/publish gate | built-in lifecycle、kill switch、compatibility 必须从 authoritative registry 收敛 |
| persisted lesson step payload → editor DTO | 单条坏 payload 来自不可信持久化数据，不能把整个 editor 打挂 |
| server-derived publishState → client status panel | blocker UI 只能显示最新服务端 truth，不能缓存过期状态 |
| verifier script → phase close decision | close gate 需要基于真实行为测试，而不是脆弱静态字符串 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-56-05-01 | T | built-in lifecycle gate | mitigate | 统一复用 `isRunnablePluginState` 与 `killSwitchEnabled` truth，authoring 与 publish 共用同一 helper 结果 |
| T-56-05-02 | D | `getLessonEditorDTO` hydration | mitigate | 对 step payload 改 safe-parse，坏数据转结构化 issue，避免单条脏数据导致 editor 全面不可用 |
| T-56-05-03 | I | `AuthoringStatusPanel` stale blockers | mitigate | blockers 直接取最新 props，并在保存后刷新时显示明确状态文案 |
| T-56-05-04 | R | `verify:phase56` close gate | mitigate | 用行为级 suites 覆盖 lifecycle/provenance/safe-parse/stale-state 回归，减少静态 includes 假阳性 |
</threat_model>
